# PAGE-023 批次与评审规则

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 批次与评审规则 |
| 角色 | 学校侧审核人员（具备批次配置权限） |
| 入口 | 学校端菜单“批次与规则” |
| 关联 API | API-035 批次与评审规则版本 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 批次 | 批次/状态/当前规则版本 | Select+StatusTag | 批次主数据来自学校同步，平台不改权威字段 |
| 任务规则 | 目标专家人数/接单期限/评阅期限 | Form | 必须由学校明确配置，不提供猜测默认值 |
| 评阅规则 | 模板版本/评分模式/汇总模式 | Form | 模板与规则版本绑定；启用后快照 |
| 冲突规则 | 结构化冲突条件 | RuleBuilder | 只使用受支持字段与运算符 |
| 异议与通知 | 异议期限/通知渠道 | Form | 未配置期限时明确显示“未配置” |
| 版本操作 | 保存/校验/对比/启用 | Button | 启用二次确认、幂等、乐观锁 |

## 四、交互与状态

- 批次名称、起止时间、组织和提交资格等学校权威字段只读；本页只维护平台评审规则版本；
- 新配置先保存为草稿；通过完整性和相容性校验后才能启用；已启用版本不可原地修改，只能复制为新版本；
- 创建送审轮次时固化规则快照，后续新版本不得改变既有轮次；
- 无汇总规则时系统只展示独立结果，不推断结论；未配置异议期限时系统不擅自阻止提交；
- 页面不预填未经学校确认的专家人数、分数阈值、期限或其他业务值；
- 并发启用返回 `VERSION_CONFLICT`，版本启用和回退动作完整审计。

## 五、数据来源与权限投影

- 数据来源：`GET /school-review/batches`、`GET/POST /school-review/batches/{id}/rule-versions`、`PATCH /school-review/batches/{id}/rule-versions/{version}`、`POST /school-review/batches/{id}/rule-versions/{version}:activate`；
- 仅本租户且具备批次配置权限的学校侧审核人员；普通只读审核人员只能查看生效版本；
- 百杰侧读取执行任务所需的规则快照，不在本页修改学校评审规则；专家、学生和导师不可见配置细节。
