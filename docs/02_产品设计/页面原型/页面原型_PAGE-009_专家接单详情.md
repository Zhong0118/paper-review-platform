# PAGE-009 专家接单详情

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 专家接单详情 |
| 角色 | 专家 |
| 入口 | 任务列表"接单" |
| 关联 API | API-019 接受/拒绝 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 专家端            通知铃  ·  用户     │
├───────────────────────────────────────────────────────┤
│ 评审任务邀请（匿名）                                     │
│                                                       │
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 邀请信息 | 送审方向/匿名题目/摘要/截止/费用/说明 | 只读 | 仅匿名概要；绝对时间 |
| 拒绝 | 拒绝原因 | Select+Input | 必填；下拉+说明 |
| 操作 | 拒绝 / 接受 | Button | 接受二次确认 + 幂等键 |

## 四、交互与状态

- 接单前只见匿名基本信息、学科、期限、费用与说明（FR-017，AC-012）；
- 接受：任务进入 `IN_REVIEW`，跳转 PAGE-010 可访问完整匿名材料；
- 拒绝：必须填原因，任务进入 `REJECTED`，通知百杰改派；
- 重复响应：幂等返回原结果；
- 接单超时：由系统关闭（`ACCEPT_TIMEOUT`），此页不再可用。

## 五、数据来源与权限投影

- 数据来源：`GET /expert/tasks/{id}/invitation`、`POST /expert/tasks/{id}:accept|reject`；
- 仅本人任务；不出现学生/导师身份、完整论文（接单前）、其他专家信息；
- 费用展示最小化，不出现银行卡等敏感信息。
