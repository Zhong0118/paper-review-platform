# PAGE-019 学校异议处理工作台

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学校异议处理工作台 |
| 角色 | 学校侧审核人员 |
| 入口 | 学校端菜单“异议处理” / 通知中心异议通知 |
| 关联 API | API-027 异议查询、API-028 结论回填 |

## 二、布局线框

```text
┌────────────────────────────────────────────────────────────────────┐
│ 顶部栏: 学校端 · 异议处理                         通知铃 · 用户       │
├──────────┬─────────────────────────────────────────────────────────┤
│ 左侧导航  │ 筛选: 批次(下拉) 状态(下拉) 学生/论文(搜索) [查询][重置]   │
│ 结果处理  │ ┌─────────────────────────────────────────────────────┐ │
│ 异议处理  │ │ 学生  论文  提交时间  状态          处理人     操作   │ │
│          │ │ {学生}{题目}{时间}   {SUBMITTED}    {--}      [受理] │ │
│          │ │ {学生}{题目}{时间}   {PROCESSING}   {审核员}  [处理] │ │
│          │ └─────────────────────────────────────────────────────┘ │
│          │                                                         │
│          │ ── 异议详情 ──                                          │
│          │ 异议理由 / 附件（授权下载） / 已发布结果快照 / 处理记录     │
│          │ 处理方式: (线上答复 / 线下处理后回填 / 学校决定正式复核)    │
│          │ 结论摘要*: [多行文本]   结论附件: [上传]                    │
│          │ [保存处理记录] [办结异议]※二次确认                         │
└──────────┴─────────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 筛选区 | 批次/状态/学生或论文 | Select+Input | 仅本租户与当前组织数据范围 |
| 列表 | 学生/论文/提交时间/异议状态/处理人 | Table | 服务端分页；不出现专家身份 |
| 详情 | 理由/附件/发布结果快照/处理记录 | Description+Timeline | 发布快照只读；附件短时授权 |
| 处理 | 处理方式/结论摘要/结论附件 | Form | 办结时结论摘要必填 |
| 操作 | 受理/保存记录/办结 | Button | 服务端允许动作驱动；办结二次确认与幂等 |

## 四、交互与状态

- `SUBMITTED` 可受理并进入 `PROCESSING`；`PROCESSING` 可追加记录并办结为 `RESOLVED`；
- 异议处理不修改论文 `COMPLETED` 状态，也不得覆盖已发布结果或专家原始结果；
- “学校决定正式复核”只记录决定和说明，后续按独立流程创建新送审轮次；本页不实现完整在线复核；
- 未配置异议期限时不显示系统推断的截止日期，也不擅自拒绝学生提交；
- 所有附件、结论和状态变化写入审计，失败时保留表单并提供重试。

## 五、数据来源与权限投影

- 数据来源：`GET /school-review/objections`、`GET /objections/{id}`、`POST /objections/{id}:record-resolution`；
- 仅学校侧审核人员按本租户与组织范围访问；不出现专家身份、联系方式或内部专家任务信息；
- 学生只能通过 PAGE-012 查看本人异议状态和获准公开的学校结论。
