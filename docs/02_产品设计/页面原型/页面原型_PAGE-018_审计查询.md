# PAGE-018 审计查询

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 审计查询 |
| 角色 | 系统管理员（系统日志）；授权审核人员（本校/平台范围） |
| 入口 | 系统管理/运营菜单"审计" |
| 关联 API | API-033 审计查询 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────────┐
│ 顶部栏: ...                      通知铃  ·  用户            │
├───────────────────────────────────────────────────────────┤
│ 审计查询                                                   │
│  筛选: 时间(范围)  操作类型(下拉)  操作人(搜索)  对象(搜索)    │
│  [查询] [重置]                                              │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ 时间        操作人  操作       对象       租户  结果   │  │
│  │ {时间}  {user} {publish} {论文ID}  {校A}  {OK}       │  │
│  │ {时间}  {user} {login}   {user}    {校A}  {FAIL}     │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                           │
│  ── 审计详情（抽屉）──                                      │
│  操作人/时间/对象/前后状态/request_id/结果                    │
│  [ 导出 ]※受数据范围限制                                    │
└───────────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 筛选 | 时间/操作类型/操作人/对象 | Form | 按职责范围 |
| 列表 | 时间/操作人/操作/对象/租户/结果 | Table | 只追加，不可改删 |
| 详情 | 前后状态/request_id/结果 | Drawer | 敏感字段受限 |
| 导出 | 导出按钮 | Button | 受数据范围限制 |

## 四、交互与状态

- 审计只追加：业务用户不可修改/删除（NFR-007）；
- 系统管理员限系统日志；学校侧限本校业务；百杰侧限平台运营（权限矩阵）；
- 操作类型覆盖：登录/权限/同步/下载/匿名确认/状态变化/指派/接拒/提交/更正/发布/异议/财务/权限变更（API 设计第 6 节）；
- 日志不包含论文正文、完整评语、令牌、对象键、签名地址（AC-025）。

## 五、数据来源与权限投影

- 数据来源：`GET /audit-events`（范围化）；
- 按数据范围过滤；敏感字段脱敏；
- 审计数据与普通应用日志分开控制（部署运维 10）。
