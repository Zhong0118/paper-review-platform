# PAGE-016 导出中心

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 导出中心 |
| 角色 | 审核人员（按数据范围） |
| 入口 | 菜单"导出中心" |
| 关联 API | API-034 导出 |

## 二、布局线框


## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 新建导出 | 类型/范围筛选 | Form+Select | 按数据范围 |
| | 创建导出任务 | Button | 异步任务返回任务号 |
| 导出记录 | 任务号/类型/范围/状态/到期/下载 | Table | 7 天失效；下载记录审计 |

## 四、交互与状态

- 异步生成，不阻塞请求；返回任务编号，可关闭页面后查询（交互规则第 8 条）；
- 下载：短时签名地址；导出文件 7 天失效并清理（FR-033/AC-026）；
- 权限：按当前角色数据范围（学校侧限本校，百杰侧限运营）；
- 失败可重试；下载记录写入审计。

## 五、数据来源与权限投影

- 数据来源：`POST /exports`、`GET /exports/{id}`；
- 导出内容遵循角色投影：学校导出不包含专家身份；百杰导出不含原始版；
- 日志不记录导出文件内容，只记录范围与下载。
