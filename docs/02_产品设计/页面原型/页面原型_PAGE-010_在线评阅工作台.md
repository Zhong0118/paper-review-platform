# PAGE-010 在线评阅工作台

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 在线评阅工作台 |
| 角色 | 专家 |
| 入口 | 任务列表"继续"（`IN_REVIEW` 后） |
| 关联 API | API-020 材料、API-021 草稿、API-022 最终提交、API-023 更正 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 阅读区 | PDF 预览 | Viewer | 仅匿名版；不可下载原件 |
| 评阅表单 | 评分项/总分/评语 | 动态 Form | 按模板版本渲染；分项或总分模式 |
| | 评语必填/字数 | 校验 | 模板必填规则 |
| 操作 | 保存草稿 / 最终提交 / 申请更正 | Button | 提交二次确认 + 幂等键 |

## 四、交互与状态

- 草稿：`PUT /expert/tasks/{id}/draft`，可反复保存；
- 最终提交：按模板校验必填项/分数范围，成功后锁定 `SUBMITTED`，不可再编辑；
- 重复提交：幂等返回原结果；
- 任务处于 `IN_REVIEW` 且 `overdue=true` 时显示逾期警告，仍可提交，不自动删除草稿（FR-021）；
- 更正申请：`POST .../correction-requests`，百杰审批后生成新版本，旧版本保留。

## 五、数据来源与权限投影

- 数据来源：`GET /expert/tasks/{id}/materials`（接受后）、`PUT .../draft`、`POST ...:submit-final`、`POST .../correction-requests`；
- 仅本人有效任务；不出现作者/导师身份、其他专家评语、原始版；
- 材料访问受 `files.authorize` 短时授权（ADR-0004）。
- 甲方演示模板的六项为：选题价值 15、文献与理论基础 15、研究方法 20、创新性 25、研究成果与工作量 15、写作与学术规范 10，合计 100；同时填写综合结论、优点、主要问题、修改建议和总体评语。
- 上述六项仅是演示批次的模板版本，页面必须按模板数据动态渲染，不得在业务组件中写死为全平台唯一评分项。

## 六、前端演示实现（2026-08-12）

以下为专家端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库或通知发送已接入。

- 实现页面 `ReviewWorkspacePage.vue`（在线评阅，PAGE-010）：左侧匿名论文材料区（`AnonymousDocumentPane` 按场景投影展示匿名题目/摘要/材料，不提供下载与原文），右侧 `ReviewFormPane` 六维评分表单按模板数据动态渲染（演示批次模板：选题价值 15、文献与理论基础 15、研究方法 20、创新性 25、研究成果与工作量 15、写作与学术规范 10，合计 100），实时总分与字段级越界提示来自模板约束。
- 保存草稿：输入变化防抖自动保存 + 手动「保存草稿」，刷新后从持久化投影回填表单（评阅投影按角色可见，学生/学校视角隐藏）；逾期任务仍可保存与提交（`overdue` 红色警告）。
- 最终提交：二次确认对话框（打开时焦点移至确认按钮，Esc/取消可关闭，提交中防重复）；提交成功后整页只读锁定（表单与材料区禁用），平台任务进入 `SUBMITTED`，专家账户入账 ¥ 300 并追加流水。
- 申请更正：提交后只读视图提供「申请更正」入口，原因必填；提交成功复位对话框（提交中/取消/Esc 行为正确），原评阅版本保留等待平台审批（PAGE-020）。
- 页面右下角在 `VITE_DEMO_MODE=true` 时提供专家端演示场景控制器（主线快照装载、六维模板切换、文件校验状态演示、一键恢复默认数据），关闭演示模式时不渲染入口。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-platform:v1` 平台投影）的不可变投影；真实评阅提交 API、通知发送与文件解析未实现。
