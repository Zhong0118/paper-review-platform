# PAGE-010 在线评阅工作台

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 在线评阅工作台 |
| 角色 | 专家 |
| 入口 | 任务列表"继续"（`IN_REVIEW` 后） |
| 关联 API | API-020 材料、API-021 草稿、API-022 最终提交、API-023 更正 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 阅读区 | PDF 预览 | Viewer | 仅匿名版；不可下载原件 |
| 评阅表单 | 评分项/总分/评语 | 动态 Form | 按模板版本渲染；分项或总分模式 |
| | 评语必填/字数 | 校验 | 模板必填规则 |
| 操作 | 保存草稿 / 最终提交 / 申请更正 | Button | 提交二次确认 + 幂等键 |

## 四、交互与状态

- 草稿：`PUT /expert/tasks/{id}/draft`，可反复保存；
- 最终提交：按模板校验必填项/分数范围，成功后锁定 `SUBMITTED`，不可再编辑；
- 重复提交：幂等返回原结果；
- 任务处于 `IN_REVIEW` 且 `overdue=true` 时显示逾期警告，仍可提交，不自动删除草稿（FR-021）；
- 更正申请：`POST .../correction-requests`，百杰审批后生成新版本，旧版本保留。

## 五、数据来源与权限投影

- 数据来源：`GET /expert/tasks/{id}/materials`（接受后）、`PUT .../draft`、`POST ...:submit-final`、`POST .../correction-requests`；
- 仅本人有效任务；不出现作者/导师身份、其他专家评语、原始版；
- 材料访问受 `files.authorize` 短时授权（ADR-0004）。
