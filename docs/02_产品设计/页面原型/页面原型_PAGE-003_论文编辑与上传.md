# PAGE-003 论文编辑与上传

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 论文编辑与上传 |
| 角色 | 学生 |
| 入口 | 工作台"新建论文/继续编辑" |
| 关联 API | API-006 草稿、API-007 版本、API-008 提交、API-011 文件 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────────┐
│ 论文编辑  →  论文提交  →  匿名检测  →  学校确认        (步骤条) │
├───────────────────────────────────────────────────────────┤
│ 基本信息                                                    │
│   题目*:   __________________________________               │
│   摘要*:   [ 多行文本框 ]                                   │
│   送审专业方向*:  (专业目录下拉)                              │
│   关键词:   __________________________________               │
│                                                           │
│ 论文文件（必填，原件与匿名件分域）                             │
│   [原始版上传]  状态: {已上传/未上传}  [重新上传]             │
│   [匿名版上传]  状态: {已上传/未上传}  [重新上传]             │
│   提示: 匿名版不得含姓名/学号/导师/致谢，文件名同规则           │
│                                                           │
│ 附件（选填）                                                 │
│   [添加附件]  附件列表(名称/大小/删除)                        │
│                                                           │
│ 操作区                                                      │
│   [ 保存草稿 ]    [ 提交送审 ]※二次确认                       │
└───────────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 基本信息 | 题目/摘要/送审专业/关键词 | Form | 专业必须选择受控目录的代码+名称；关键词为可增删 Tag 数组并自动去重 |
| 学籍与资格 | 学号/姓名/学校/学院/学位层次/学位类型/导师/批次 | Description | 学校权威只读，不允许学生在平台修改 |
| 论文文件 | 原始版上传 | Upload | 必填；类型/大小/可读性/加密校验；进度+失败重试 |
| | 匿名版上传 | Upload | 必填；同校验；上传后触发匿名检测 |
| | 附件 | Upload | 选填；类型/大小校验 |
| 操作 | 保存草稿 / 提交送审 | Button | 提交需二次确认 + 防重复（幂等键） |

## 四、交互与状态

- 匿名检测返回 `FAIL`：提交阻断或提交后退回 `DRAFT`，弹出结构化检查项（正文/文件名/元数据/致谢），提示定位但不泄露额外信息；
- 匿名检测返回 `REVIEW_REQUIRED`：论文进入学校人工确认队列；`PASS` 仍需学校完成最终确认；
- 文件校验失败：字段级错误 + 可重试；
- 保存草稿：`PATCH /theses/{id}`，可反复保存；
- 提交送审：`POST /theses/{id}:submit`（幂等），成功进入 `SUBMITTED` 并返回学生工作台，展示“已提交/匿名检测中”及后续状态；
- 派单前撤回入口在此页或工作台：`POST /theses/{id}:withdraw`，返回 `DRAFT` 并提示版本保留。

## 五、数据来源与权限投影

- 数据来源：`GET/PATCH /theses/{id}`、`POST /theses/{id}/versions`、`POST /files:*`；
- 仅本人论文；专家/学校侧不可见此页编辑内容；
- 送审专业方向来自平台专业目录（受控编码）；学生按方向选择不等于指定专家。
- 请求同时保存 `discipline_code`、`discipline_name` 和 `keywords: string[]`，不得以自由文本替代专业代码。
- 专业帮助文案：“可按专业代码或名称搜索，请选择与论文研究内容最匹配的送审专业。”
- 关键词帮助文案：“输入后按 Enter 或分号生成标签，用于辅助专家匹配；完全重复的词会自动合并，建议填写 3—5 个。”
- 专业选择器默认收起，仅在点击/聚焦后打开，支持点击外部和 `Esc` 关闭。

## 六、前端演示实现（2026-08-11）

以下为学生端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库、文件解析或匿名检测已接入。

- 实现页面 `ThesisEditPage.vue`：支持 `?thesisId=new` 新建草稿并以服务返回的真实草稿 ID 替换路由参数；加载失败提供“重新加载”，错误提示后不丢失页面标题。
- 学籍与送审批次使用只读 `StudentIdentityPanel`（学校/学院/学号/姓名/培养层次/学位类型/导师/批次/截止时间），不允许学生修改。
- 专业选择器 `DisciplineSelector` 使用教育部《研究生教育学科专业目录（2022 年）》184 个受控条目（117 个一级学科 + 67 个专业学位类别），按代码或名称搜索；桌面端为绝对定位浮层（`position: absolute; z-index: 30`），移动端（≤640px）为固定底部弹层（`position: fixed; inset: auto 0 0; max-height: 70vh`），不挤压页面布局；打开聚焦搜索框，`Esc` 或点击外部关闭并把焦点还给控制按钮。
- 关键词 `KeywordTagInput` 输入后按 Enter/分号生成标签，去空白并完全去重，最多 5 个，超限提示“最多填写 5 个关键词，请先删除已有关键词。”。
- 文件域 `ThesisFileField` 只保存 `{id,name,size,mimeType,purpose,validationStatus}` 六个元数据字段，不读取正文、不把 `File` 或二进制写入本地存储；模拟选择/校验/失败状态，失败提供“重新选择”并保留本地表单；匿名版文件名或正文含姓名/学号/“致谢”等身份线索时标记 `REVIEW_REQUIRED` 并提示“请检查文件名和正文中的身份线索”，明确不宣称正文已自动检测。
- 表单变化置脏（显示“有未保存修改”），离开页面前弹确认；保存成功显示“已保存 · 时间”，保存失败保留输入并提供“重新保存”；提交学校审核二次确认、防重复点击，成功后返回工作台并展示“已提交”。
- 校验失败顺序固定为题目、摘要、专业、关键词、原始版、匿名版，并聚焦首个错误字段。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-student:v1`）；真实上传、`PATCH/POST /theses`、文件解析、匿名检测与幂等提交 API 未实现。
