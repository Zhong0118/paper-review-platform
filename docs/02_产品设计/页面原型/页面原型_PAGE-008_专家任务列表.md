# PAGE-008 专家任务列表

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 专家任务列表 |
| 角色 | 专家 |
| 入口 | 专家登录后默认页 |
| 关联 API | API-018 任务列表/邀请 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 专家端            通知铃  ·  用户     │
├───────────────────────────────────────────────────────┤
│ 我的评审任务                                             │
│  筛选: 状态(下拉)                                        │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 任务状态      送审方向  接单截止/评阅截止   操作     │  │
│  │ {INVITED}     {方向}   {截止时间}        [接单]    │  │
│  │ {IN_REVIEW}   {方向}   {评阅截止}        [继续]    │  │
│  │ {IN_REVIEW}+逾期 {方向} {已逾期}          [继续]    │  │
│  │ {SUBMITTED}   {方向}   {已提交}          [查看]    │  │
│  └─────────────────────────────────────────────────┘  │
│                                                       │
│  统计: 待接单 {N} · 评阅中 {N} · 已提交 {N}             │
└───────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 任务列表 | 任务状态/送审方向/截止时间 | Table | 仅本人任务 |
| | 操作（接单/继续/查看） | Button | 由任务状态驱动 |
| 统计 | 待接单/评阅中/已提交 | 只读 | 计数 |

## 四、交互与状态

- `INVITED`：仅"接单"进入 PAGE-009（接单前只见匿名概要）；
- `IN_REVIEW`：评阅中，"继续"进入 PAGE-010；
- `IN_REVIEW` 且 `overdue=true`：附加“已逾期”警告标签，仍可“继续”评阅，不自动删除草稿（FR-021）；
- `SUBMITTED`：最终提交锁定，"查看"只读；
- 状态按钮由服务端允许动作驱动；接单/拒绝见 PAGE-009。

## 五、数据来源与权限投影

- 数据来源：`GET /expert/tasks`；
- 仅本人任务；不出现学生/导师身份、其他专家评语、原始版；
- 逾期使用布尔/时限属性 `overdue`，不得作为独立任务状态（02 唯一枚举表）。
