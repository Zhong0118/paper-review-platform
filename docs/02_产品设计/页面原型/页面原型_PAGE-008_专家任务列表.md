# PAGE-008 专家任务列表

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 专家任务列表 |
| 角色 | 专家 |
| 入口 | 专家登录后默认页 |
| 关联 API | API-018 任务列表/邀请 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 任务列表 | 任务状态/送审方向/截止时间 | Table | 仅本人任务 |
| | 操作（接单/继续/查看） | Button | 由任务状态驱动 |
| 统计 | 待接单/评阅中/即将截止/已提交 | 只读 | 计数 |
| 列表补充 | 任务编号/匿名题目/评审费用 | Table | 不显示学生、导师、原始版或其他专家 |

## 四、交互与状态

- `INVITED`：仅"接单"进入 PAGE-009（接单前只见匿名概要）；
- `IN_REVIEW`：评阅中，"继续"进入 PAGE-010；
- `IN_REVIEW` 且 `overdue=true`：附加“已逾期”警告标签，仍可“继续”评阅，不自动删除草稿（FR-021）；
- `SUBMITTED`：最终提交锁定，"查看"只读；
- 状态按钮由服务端允许动作驱动；接单/拒绝见 PAGE-009。

## 五、数据来源与权限投影

- 数据来源：`GET /expert/tasks`；
- 仅本人任务；不出现学生/导师身份、其他专家评语、原始版；
- 逾期使用布尔/时限属性 `overdue`，不得作为独立任务状态（02 唯一枚举表）。

## 六、前端演示实现（2026-08-12）

以下为专家端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库或通知发送已接入。

- 实现页面 `ExpertTasksPage.vue`（评审任务，PAGE-008）：状态分组页签（待接受/评阅中/已完成/已拒绝/已撤销/需要更正）按服务端任务投影过滤，仅展示本人任务；接单前仅见匿名概要、截止时间、费用与评审说明，不出现学生/导师身份与原始论文。
- 任务行在 ≤900px 视口自动切换为卡片布局（隐藏表头、双列卡片），390px 无整页横向滚动；逾期任务以布尔/时限属性 `overdue` 标记（红色警告），不作为独立状态。
- 任务列表数据平台权威：专家端服务投影以平台 `expertTasks` 为准回退演示种子；「继续评阅/查看详情」跳转在线评阅工作台（PAGE-010）与接单详情（PAGE-009）。
- 页面右下角在 `VITE_DEMO_MODE=true` 时提供专家端演示场景控制器（待接受/评阅中/逾期评阅中/已提交（只读）/需要更正/已拒绝等主线快照装载、六维模板切换、文件校验状态演示、一键恢复默认数据），关闭演示模式时不渲染入口。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-platform:v1` 平台投影 + `baijie-demo-student:v1` 学生快照）的不可变投影；真实任务 API、SSO 与通知发送未实现。
