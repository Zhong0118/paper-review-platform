# 页面原型 · 总览与布局

## 1. 原型目的与阅读方式

本套原型是**字段级低保真设计**：用 ASCII 线框 + 字段/组件清单 + 交互说明，表达每个页面的布局、字段、组件和数据投影。不作为可运行的 UI，也不作为最终视觉稿；最终视觉由 `docs/ui-design-system.md` 约束。

每个页面原型文档统一包含：

| 章节 | 内容 |
|---|---|
| 一、页面信息 | 页面编号/名称/角色/入口 |
| 二、布局线框 | ASCII 线框（标注区号） |
| 三、字段与组件清单 | 每个区内的字段/组件、类型、约束 |
| 四、交互与状态 | 按钮动作、状态三态、防重复、二次确认 |
| 五、数据来源与权限投影 | 关联 API、角色数据范围、盲审隔离约束 |

## 3. 页面骨架与布局策略

页面不设置全局最大宽度，按角色任务和信息密度使用四套骨架。学校侧与百杰运营侧使用带侧栏的后台骨架：

```text
┌──────────────────────────────────────────────────────────┐
│ 顶部栏:  Logo · 面包屑                通知铃  ·  用户下拉   │ ← 固定高 56
├──────────┬───────────────────────────────────────────────┤
│ 左侧导航  │  页面标题区:  标题 + 主操作按钮                  │ ← 标题区
│ (菜单)   ├───────────────────────────────────────────────┤
│          │  筛选区(列表页): 筛选条件 + 查询/重置             │
│          ├───────────────────────────────────────────────┤
│          │  主内容区: 表格 / 表单 / 详情（利用可用视口）       │ ← 滚动区
│          │                                               │
└──────────┴───────────────────────────────────────────────┘
```

- **学校后台**：PAGE-004、005、011、019、023；左侧导航强调送审、结果和异议闭环。
- **百杰运营后台**：PAGE-006、007、020、022；左侧导航强调专家、派单、时效和结算。
- **学生/导师门户**：PAGE-002、003、012、013；顶部导航 + 聚焦当前任务的内容区，表单正文控制阅读行长但不限制页面容器。
- **专家门户**：PAGE-008、009、010、014、021；普通页面采用顶部导航，PAGE-010 使用全视口双栏评阅工作台。
- PAGE-015—018 按当前角色嵌入对应骨架；系统管理员使用独立系统管理侧栏。
- 布局骨架用 Tailwind（flex/grid + `min-width: 0` + 分区滚动），详细规则见 `docs/ui-design-system.md` 第 3 节。

## 4. 线框与标注约定

- 用 `[ ]` 表示按钮，`____` 表示输入框，`[表格]` 表示表格区，`(下拉)` 表示选择器；
- 字段后标注：`必填` / `选填` / `只读` / `服务端允许动作`;
- 操作旁标注二次确认：`[发布]※二次确认`；
- 状态用 `{状态}` 占位，映射 ui-design-system 状态标签配色。

## 5. 盲审与权限投影总原则

- 学校侧页面：不出现专家姓名/联系方式/专家列表；学生/导师可识别。
- 百杰运营页：可出现学生/导师与专家身份（运营需要），但不得出现原始版；不出现专家在其他学校的任务。
- 专家页：不出现学生/导师身份、其他专家评语；仅本人任务。
- 学生/导师页：仅本人/本人学生的已发布匿名结果；不出现专家身份。
- 系统管理页：租户/账号/配置，默认不出现论文正文/评阅内容。
- 所有状态按钮由服务端允许动作驱动，前端不推断（02 产品设计交互规则第 1 条）。

## 6. 通用组件引用

- 状态标签：`StatusTag`（映射 02 唯一枚举表配色，ui-design-system 4.5）；
- 空值：`--`；日期：`YYYY-MM-DD HH:mm`；截止时间：租户时区绝对时间（交互规则第 7 条）；
- 列表三态：加载/空数据/错误（含重试）；
- 危险操作：红色 + 二次确认；操作 >3 个收"更多"菜单。
