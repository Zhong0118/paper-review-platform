# PAGE-014 提现与结算

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 提现与结算 |
| 角色 | 专家 |
| 入口 | 专家端“我的余额” |
| 关联 API | API-030 余额/流水、API-031 提现；百杰处理见 PAGE-022/API-032 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 账户 | 可提现/冻结金额 | 只读 | 来自流水汇总 |
| 提现申请 | 金额 | Input | 必填；≤可提现；二次确认 |
| 提现记录 | 时间/金额/状态/付款时间 | Table | 状态枚举 `SUBMITTED/REVIEWING/PAID/REJECTED/REVERSED` |
| 流水 | 入账/冲正记录 | Table | 只追加，可审计 |

## 四、交互与状态

- 专家提交申请后只能查看处理状态，不能自行改为已付款或撤销账务记录；
- 审核驳回时展示可公开原因，冻结余额由服务端解除；
- P0 不自动调用支付供应商，百杰侧审核与线下付款回填在 PAGE-022 完成；
- 重复申请/并发：幂等键 + 唯一约束防重复。

## 五、数据来源与权限投影

- 专家：`GET /expert/account`、`GET /expert/ledger`、`POST /expert/withdrawals`；
- 专家仅访问本人账户、流水和申请；百杰侧使用 PAGE-022 的授权财务投影；收款信息默认脱敏；
- 金额用最小单位/Decimal，禁浮点。

## 六、前端演示实现（2026-08-12）

以下为专家端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库或支付已接入。

- 实现页面 `ExpertFinancePage.vue`（费用与提现，PAGE-014）：账户摘要（可提现/冻结/累计入账）、流水列表（种子 3 笔 + 最终提交入账 ¥ 300 + 提现冻结 + 付款出账等演示流水）与提现申请表单；金额展示统一两位小数。
- 提现申请：金额 ≤ 可提现余额才允许提交；提交后生成 `PENDING` 申请（写平台投影），进入运营端 PAGE-022 结算队列等待审核；重复提交被幂等拦截。
- 收款信息默认脱敏（掩码展示 + 「查看完整信息」仅演示投影提示），不出现真实银行卡等敏感信息。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-platform:v1` 平台投影）的不可变投影；真实账户 API、银行支付与提现渠道未实现。
