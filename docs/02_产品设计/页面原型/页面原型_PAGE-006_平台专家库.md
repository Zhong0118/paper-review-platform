# PAGE-006 平台专家库

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 平台专家库 |
| 角色 | 百杰侧审核人员 |
| 入口 | 百杰运营端菜单"专家库" |
| 关联 API | API-012 专家与资格 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────────┐
│ 顶部栏: 百杰运营 · 专家库                 通知铃  ·  用户     │
├──────────┬────────────────────────────────────────────────┤
│ 左侧导航  │  筛选: 擅长领域(下拉)  状态(下拉)  关键字 [查询][重置]│
│ 专家库    │                                                │
│ 派单工作台│  [ 新增专家 ]  [ 批量导入 ]                      │
│          │  ┌───────────────────────────────────────────┐ │
│          │  │ 专家姓名  擅长领域    资格状态  服务状态  操作  │ │
│          │  │ {专家}  {领域}     {通过}   {可用}   [编辑]  │ │
│          │  │ {专家}  {领域}     {审核中} {禁用}   [编辑]  │ │
│          │  └───────────────────────────────────────────┘ │
│          │                                                │

└──────────┴────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 筛选 | 擅长领域/状态/关键字 | Select+Input | 受控标签/编码 |
| 列表 | 专家姓名/擅长领域/资格状态/服务状态 | Table | 平台级数据，跨校可复用 |
| 详情 | 基本信息/资格/资质文件 | Form | 百杰侧维护运营字段并审核资格；专家本人维护见 PAGE-021 |
| | 回避管理 | Table+Form | 命中回避禁止指派（T-016） |

## 四、交互与状态

- 资格状态：`通过/审核中/驳回`；驳回需理由；
- 服务状态：`可用/禁用`；禁用后新任务不可指派，既有任务不受影响；
- 新增/编辑：二次确认；重要变更（联系方式/资格）写审计；
- 列表三态 + 服务端分页；
- 专家跨校复用但学校侧不可见本库（平台级数据）。

## 五、数据来源与权限投影

- 数据来源：`/platform-review/experts`、`/experts/{id}/qualifications`；
- 百杰运营侧可见专家完整身份（派单/运营需要，Q-014）；
- 学校侧不可见此页；系统管理员默认不接触专家业务内容；
- 不出现学生/导师身份、论文内容。
