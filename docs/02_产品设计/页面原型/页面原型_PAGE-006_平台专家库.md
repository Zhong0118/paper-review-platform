## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 筛选 | 擅长领域/状态/关键字 | Select+Input | 受控标签/编码 |
| 列表 | 姓名/单位/职称/学科与擅长领域/资格/服务状态/当前负载/接单率/按时完成率 | Table | 平台级数据，跨校可复用；学校不可访问 |
| 详情 | 基本信息/资格/资质文件 | Form | 百杰侧维护运营字段并审核资格；专家本人维护见 PAGE-021 |
| | 回避管理 | Table+Form | 命中回避禁止指派（T-016） |
| 统计 | 专家总数/可派/待审资格/即将到期/已停用 | Statistic | 只展示可驱动处理的数量 |
| 详情 | 基本资料/资格/回避/历史任务/费用摘要/操作日志 | Drawer | 历史任务不对学校投影 |

## 四、交互与状态

- 资格状态：`通过/审核中/驳回`；驳回需理由；
- 服务状态：`可用/禁用`；禁用后新任务不可指派，既有任务不受影响；
- 新增/编辑：二次确认；重要变更（联系方式/资格）写审计；
- 列表三态 + 服务端分页；
- 专家跨校复用但学校侧不可见本库（平台级数据）。

## 五、数据来源与权限投影

- 数据来源：`/platform-review/experts`、`/experts/{id}/qualifications`；
- 百杰运营侧可见专家完整身份（派单/运营需要，Q-014）；
- 学校侧不可见此页；系统管理员默认不接触专家业务内容；
- 不出现学生/导师身份、论文内容。

## 六、前端演示实现（2026-08-12）

以下为百杰运营端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库、SSO、文件解析或通知发送已接入。

- 实现页面 `ExpertLibraryPage.vue`（专家库，PAGE-006）：统计卡片（专家总数/可派/待审资格/即将到期/已停用）、关键字筛选与重置、专家列表（桌面表格，≤900px 自动切换为卡片视图）、新增/批量导入为演示入口（不真实入库）。
- 详情抽屉 `ExpertProfileDrawer` 六个页签：基本资料/资格与材料/回避管理/历史任务/费用摘要/操作日志；资质材料仅展示文件名、类型、有效期与审核状态元数据投影，不读取正文；「暂停接单/恢复接单」二次确认并填写操作原因，写运营审计。
- 资格审核（通过/驳回）与演示人格联动：演示专家人格（expert-17 周明远）初始资格为「审核中」，资格通过后进入送审运营台候选列表方可派单。
- 操作日志与历史任务为演示批次汇总投影，不对学校投影；页面右下角在 `VITE_DEMO_MODE=true` 时提供运营端演示场景控制器（六个主线场景、专家资格、服务状态、文件校验、一键恢复默认数据），关闭演示模式时不渲染入口。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-platform:v1`）的不可变投影；真实专家档案 API、资格审核 API、SSO 与文件解析未实现。
