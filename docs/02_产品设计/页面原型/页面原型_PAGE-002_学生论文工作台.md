# PAGE-002 学生论文工作台

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学生论文工作台 |
| 角色 | 学生 |
| 入口 | 学生登录后默认页 |
| 关联 API | API-006 草稿、API-026 结果、API-027 异议 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 我的论文            通知铃  ·  用户   │
├───────────────────────────────────────────────────────┤
│ 我的提交资格                                            │
│   {批次名}  提交截止: 2026-xx-xx      {资格状态}         │
│                                                       │
│ 我的论文                                                │
│  [ 新建论文 ]                                            │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 题目           批次        状态        操作       │  │
│  │ 基于…的研究   2026春     {UNDER_REVIEW}  [查看]   │  │
│  │ 基于…的研究   2025秋     {COMPLETED}    [查看]   │  │
│  └─────────────────────────────────────────────────┘  │
│                                                       │
│ 我的送审进度（当前论文）                                  │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 步骤: 提交 → 准备中 → 送审中 → 结果处理 → 完成     │  │
│  │ 当前: {送审中}  专家已评 2/3                        │  │
│  └─────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 资格卡 | 批次名/提交截止/资格状态 | 卡片 | 只读；来自 `student_eligibilities` |
| 论文列表 | 题目/批次/状态 | Table | 服务端分页 |
| | 操作（查看/继续编辑） | Button | 由服务端允许动作驱动 |
| 进度条 | 步骤指示 | Steps | 当前阶段高亮；来自论文状态 |

## 四、交互与状态

- 无资格或批次已过期：资格卡显示 `SUSPENDED/EXPIRED`，禁用"新建论文"并提示原因；
- 无论文：空状态 + 引导"新建论文"；
- 列表三态：加载/空/错误（重试）；
- 状态按钮服务端驱动：`DRAFT`→继续编辑；`SUBMITTED~READY_FOR_DISPATCH`→可撤回（见 PAGE-003/005 交互）；`COMPLETED`→查看结果（PAGE-012）。

## 五、数据来源与权限投影

- 数据来源：`GET /theses`、`GET /me/contexts`（资格）；
- 仅本人论文；不出现专家身份、其他学生数据；
- 未发布结果不可见（服务端投影）。
