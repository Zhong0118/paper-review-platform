# PAGE-002 学生论文工作台

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学生论文工作台 |
| 角色 | 学生 |
| 入口 | 学生登录后默认页 |
| 关联 API | API-006 草稿、API-026 结果、API-027 异议 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 资格卡 | 批次名/提交截止/资格状态 | 卡片 | 只读；来自 `student_eligibilities` |
| 论文列表 | 题目/批次/专业代码与名称/接入来源/状态/更新时间 | Table | 服务端分页；支持本人多篇论文 |
| | 操作（查看/继续编辑） | Button | 由服务端允许动作驱动 |
| 进度条 | 步骤指示 | Steps | 当前阶段高亮；来自论文状态 |
| 统计 | 待我处理/送审中/已完成 | Statistic | 只展示能驱动处理的数量 |
| 详情 | 论文阶段时间线/退回原因 | Drawer | 不显示专家身份 |

## 四、交互与状态

- 无资格或批次已过期：资格卡显示 `SUSPENDED/EXPIRED`，禁用"新建论文"并提示原因；
- 无论文：空状态 + 引导"新建论文"；
- 列表三态：加载/空/错误（重试）；
- 状态按钮服务端驱动：`DRAFT`→继续编辑；`SUBMITTED~READY_FOR_DISPATCH`→可撤回（见 PAGE-003/005 交互）；`COMPLETED`→查看结果（PAGE-012）。
- 学校代传或批量导入的本人论文同样进入列表，来源分别显示“学校代传”“学校批量导入”；学校接入来源的记录只读，不出现编辑动作。

## 五、数据来源与权限投影

- 数据来源：`GET /theses`、`GET /me/contexts`（资格）；
- 仅本人论文；不出现专家身份、其他学生数据；
- 未发布结果不可见（服务端投影）。

## 六、前端演示实现（2026-08-11）

以下为学生端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库或文件处理已接入。

- 实现页面 `StudentDashboardPage.vue`：论文列表按“全部/待我处理/送审中/已完成”筛选并统计，支持按题目、盲审编号、专业代码或名称搜索；表格行可选中，选中后五阶段进度条与操作区同步切换。
- 五阶段进度 `ThesisStageRail` 只接收学生可见阶段 `MATERIALS/SCHOOL_REVIEW/EXPERT_REVIEW/RESULT_PROCESSING/COMPLETED`；“待我处理”按论文状态自动归类（如“请修改后重新提交”“无需处理”）。
- 详情抽屉展示公开时间线、退回原因（如“匿名版仍包含可识别身份信息”）、材料文件元数据与允许动作，不显示专家身份。
- 动作按钮由服务端投影允许动作驱动：草稿可编辑/删除；学校审核期可“撤回”（派单前，二次确认并填写原因）；送审中仅可“申请撤回”（创建申请，不改变论文阶段）；已完成可“查看结果”。
- 首次加载自动选中“待我处理”首篇或第一篇论文；无论文时展示空状态引导“新建论文”，点击调用 `createStudentDraft()` 后进入编辑页；资格无效时禁用新建并展示公开原因。
- 页面右下角在 `VITE_DEMO_MODE=true` 时提供演示场景控制器（六个主线场景、资格、文件校验、一键重置），关闭演示模式时不渲染入口。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-student:v1`）的不可变投影；真实 SSO、`GET /theses`、服务端分页与资格 API 未实现。
