# PAGE-015 通知中心

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 通知中心 |
| 角色 | 全部用户（按数据范围） |
| 入口 | 顶部栏通知铃 / 菜单"通知" |
| 关联 API | API-029 通知 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: ...                    通知铃(N) ·  用户        │
├───────────────────────────────────────────────────────┤
│ 通知中心                                               │
│  筛选: 类型(下拉)  已读(下拉)                           │
│  [ 全部已读 ]                                           │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 类型    标题                时间       状态       │  │
│  │ {催审}  {您的评阅任务即将截止} {时间}  {未读}      │  │
│  │ {派单}  {您被指派新评审任务}   {时间}  {未读}      │  │
│  │ {发布}  {您的论文结果已发布}   {时间}  {已读}      │  │
│  └─────────────────────────────────────────────────┘  │
│                                                       │
│  ── 通知详情（抽屉）──                                   │
│  标题 + 正文 + 关联对象链接（任务/论文/结果） + [标记已读]  │
└───────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 列表 | 类型/标题/时间/已读状态 | Table | 按数据范围 |
| | 全部已读 | Button | 批量 |
| 详情 | 标题/正文/关联链接/标记已读 | Drawer | 敏感内容最小化 |

## 四、交互与状态

- 通知类型：派单/催审/发布/异议/超时改派等（模板版本化渲染）；
- 未读数在顶部铃显示；点击跳转详情；
- 敏感内容最小化：不包含论文正文、完整评语、身份映射（NFR-002）；
- 外部渠道（短信/邮件）发送状态仅在管理侧可查，用户端只显示站内。

## 五、数据来源与权限投影

- 数据来源：`GET /notifications`、`POST /notifications/{id}:read`；
- 按数据范围：学校侧限本校、百杰侧限运营、学生/导师/专家限本人；
- 通知正文不携带被隔离身份（专家姓名、作者身份等）。
