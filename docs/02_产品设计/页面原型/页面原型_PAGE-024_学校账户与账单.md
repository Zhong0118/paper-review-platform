# PAGE-024 学校账户与账单

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学校账户与账单 |
| 角色 | 学校侧审核人员 |
| 入口 | 学校端菜单“学校账户与账单” |
| 关联 API | API-038 学校账户与送审账单 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────────────┐
│ 顶部栏: 学校端 · 学校账户与账单                    通知铃 · 用户 │
├──────────┼──────────────────────────────────────────────────────┐
│ 左侧导航  │ [可用额度] [冻结额度] [当月消费] [累计消费]       │
│          │ 筛选: 批次  账单状态  盲审编号/学生  时间  [查询]  │
│          │ ┌────────────────────────────────────────────────┐ │
│          │ │ 账单号  盲审号  学生  批次  金额  状态  时间  操作 │ │
│          │ │ {ID}   {HY}   {学生} {批次} {300} {已消费} {time} [详情]│ │
│          │ └────────────────────────────────────────────────┘ │
│          │ 账单详情: 费用快照 / 冻结 / 扣减 / 释放 / 冲正流水       │
└──────────┴──────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 额度摘要 | 可用/冻结/当月/累计消费 | Statistic | 只读；金额使用 Decimal/最小单位格式化 |
| 筛选 | 批次/状态/盲审编号/学生/时间 | Form | 仅本租户 |
| 账单列表 | 账单号/盲审号/学生/批次/金额/状态/时间 | Table | 服务端分页；不展示专家身份 |
| 账单详情 | 规则版本/费用快照/冻结/扣减/释放/冲正 | Drawer+Timeline | 历史只读，不覆盖流水 |

## 四、交互与状态

- 学校端只读，不提供扫码充值或任意改额度；
- 确认送审后形成 `FROZEN`；有效评阅后转 `CONSUMED`；按规则取消时转 `RELEASED/CANCELLED`；
- 额度不足时 PAGE-005 阻止确认送审，已通过材料审核的论文保留在待送审；
- 列表必须具有加载、空、错误重试和无权限状态。

## 五、数据来源与权限投影

- 数据来源：`GET /school-review/account`、`GET /school-review/bills`、`GET /school-review/bills/{id}`；
- 学校只查看本租户额度和账单；学生、导师、专家不访问本页；
- 学校账户额度与专家可提现余额是独立账务边界。
