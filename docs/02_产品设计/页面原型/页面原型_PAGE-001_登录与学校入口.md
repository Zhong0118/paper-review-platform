# PAGE-001 登录与学校入口

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 登录/学校入口 |
| 角色 | 全部用户 |
| 入口 | 未认证时所有路由重定向至此 |
| 关联 API | API-001 登录/刷新/登出 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 登录表单 | 账号 | Input | 必填；专家/审核人员/管理员平台账号 |
| | 密码 | Input(password) | 必填；回车提交 |
| | 登录按钮 | Button(primary) | 提交时 loading 防重复 |
| | 忘记密码 | Link | 弱操作 |
| SSO | 学校身份登录 | Button(default) | 学生/导师使用，跳转学校 SSO |

## 四、交互与状态

- 登录失败：错误提示 `AUTH_REQUIRED`(401)，统一"账号或密码错误"，不区分用户是否存在（防枚举）；
- 限流：429 提示"操作过于频繁"；
- 登录成功：进入 `/me` 返回的默认上下文对应首页；
- 忘记密码：平台账号走找回流程；学校 SSO 用户不提供本地找回（走学校）。

## 五、数据来源与权限投影

- `POST /auth/login` 返回 access_token + refresh_token + user + contexts；
- 前端将 token 存入 Pinia `auth` store；不持久化到 localStorage（安全偏好，见工程规范 4.3）；
- 登录页无租户/盲审数据；不展示任何学校或专家信息。
