# PAGE-012 学生结果与异议

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学生结果与异议 |
| 角色 | 学生 |
| 入口 | 工作台"查看结果"（论文 `COMPLETED`） |
| 关联 API | API-026 发布结果、API-027 异议；学校结论由 PAGE-019/API-028 回填 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 我的论文            通知铃  ·  用户   │
├───────────────────────────────────────────────────────┤
│ 我的评审结果（论文: {题目}）                              │
│                                                       │
│  汇总:  {平均分/总分}   (规则: 分项平均/总分/无规则)       │
│                                                       │
│  [各专家结果 - 匿名]                                     │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 专家结果   分数    获准评语       状态             │  │
│  │ {专家一}   {82}   [查看评语]     {有效}           │  │
│  │ {专家二}   {85}   [查看评语]     {有效}           │  │
│  └─────────────────────────────────────────────────┘  │
│  注: 专家身份隐藏，仅展示匿名结果标识                       │
│                                                       │
│  ── 异议登记 ──                                         │
│  异议理由*:  [ 多行文本框 ]                              │
│  [添加附件](选填)                                         │
│  [ 提交异议 ]※二次确认                                    │
│  异议状态: {已提交/处理中/已办结}  学校结论: [查看]         │
└───────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 汇总区 | 汇总分数/规则模式 | 只读展示 | 无规则时仅展示各独立结果，不显示汇总 |
| 专家结果表 | 匿名结果标识/分数/获准评语 | Table | 专家身份隐藏；仅已发布可见 |
| 异议表单 | 异议理由/附件 | Form+Upload | 理由必填；附件类型/大小校验 |
| | 提交异议 | Button | 二次确认 + 幂等键 |
| 异议状态 | 状态标签/学校结论 | StatusTag | 映射异议状态枚举 |

## 四、交互与状态

- 发布前（论文非 `COMPLETED`）：此页不可见（服务端投影）；
- 异议提交后不可撤回，状态 `SUBMITTED → PROCESSING → RESOLVED`；
- 附件越权或超期：拒绝提交并提示；
- 学校决定正式复核：显示提示"学校已启动复核"，按独立流程查看新轮次。

## 五、数据来源与权限投影

- 数据来源：`GET /my/theses/{id}/published-result`、`POST /my/theses/{id}/objections`、`GET /objections/{id}`；
- 仅本人结果；专家身份、未发布结果不可见；
- 异议独立于论文宏观状态，不改变论文阶段。
