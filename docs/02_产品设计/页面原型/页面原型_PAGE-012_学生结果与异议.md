# PAGE-012 学生结果与异议

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学生结果与异议 |
| 角色 | 学生 |
| 入口 | 工作台"查看结果"（论文 `COMPLETED`） |
| 关联 API | API-026 发布结果、API-027 异议；学校结论由 PAGE-019/API-028 回填 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 汇总区 | 汇总分数/规则模式 | 只读展示 | 无规则时仅展示各独立结果，不显示汇总 |
| 专家结果表 | 匿名结果标识/分数/获准评语 | Table | 专家身份隐藏；仅已发布可见 |
| 异议表单 | 异议理由/附件 | Form+Upload | 理由必填；附件类型/大小校验 |
| | 提交异议 | Button | 二次确认 + 幂等键 |
| 异议状态 | 状态标签/学校结论 | StatusTag | 映射异议状态枚举 |

## 四、交互与状态

- 发布前（论文非 `COMPLETED`）：此页不可见（服务端投影）；
- 异议提交后不可撤回，状态 `SUBMITTED → PROCESSING → RESOLVED`；
- 附件越权或超期：拒绝提交并提示；
- 学校决定正式复核：显示提示"学校已启动复核"，按独立流程查看新轮次。

## 六、前端演示实现（2026-08-11）

以下为学生端前端演示证据，仅表示页面可交互闭环，不代表真实 API、数据库、文件解析或通知发送已接入。

- 实现页面 `StudentResultPage.vue`：一级导航进入时显示本人论文选择器（`?thesisId=` 直达）；未发布时仅显示五阶段进度与最近公开事件，已发布时显示综合总分、六个评分维度（选题价值/文献与理论/研究方法/创新性/成果与工作量/写作规范）、结论、公开评语、发布时间和匿名专家结果，不序列化专家真实姓名、联系方式或内部处理记录。
- 异议表单 `StudentObjectionForm`：理由与处理诉求均必填；附件按与编辑页相同的六个元数据字段规则保存（`purpose='OBJECTION'`），模拟失败时保留理由与诉求、仅标记该附件失败并提供“重新选择附件”，未恢复前禁用最终提交。
- 提交异议二次确认后创建 `SUBMITTED` 记录并生成学生通知；存在未解决异议（`SUBMITTED/PROCESSING`）时隐藏新建表单并展示处理时间线（`StudentObjectionTimeline`）；`RESOLVED` 后可查看结论但不改变论文 `COMPLETED` 阶段；重复提交被拒绝并提示“该论文已有未解决异议”。
- 学生消息中心（PAGE-015）通知点击先标记已读，再跳转到本人论文结果/异议页或工作台，目标始终携带本人论文标识。
- 演示实现为内存场景服务（localStorage 键 `baijie-demo-student:v1`）；真实 `GET/POST` 结果与异议 API、通知发送、文件解析未实现。

## 五、数据来源与权限投影

- 数据来源：`GET /my/theses/{id}/published-result`、`POST /my/theses/{id}/objections`、`GET /objections/{id}`；
- 仅本人结果；专家身份、未发布结果不可见；
- 异议独立于论文宏观状态，不改变论文阶段。
