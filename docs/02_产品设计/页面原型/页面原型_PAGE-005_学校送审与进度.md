# PAGE-005 学校送审与进度

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 学校送审与进度 |
| 角色 | 学校侧审核人员 |
| 入口 | 学校端菜单"送审进度" |
| 关联 API | API-009 撤回/终止、API-010 确认送出、API-024 去标识结果 |

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 列表 | 学生/题目/论文阶段/轮次状态/任务进度 | Table | 状态分层展示；任务进度仅数量/化名，不出现专家身份 |
| 详情 | 阶段步骤条 | Steps | 当前阶段高亮 |
| | 撤回申请 | Button | 派单后撤回需审批；二次确认 |
| | 永久终止 | Button(danger) | 仅学校侧；填原因；不可逆 |
| | 查看时效/联系百杰运营 | Button/Link | 学校侧只读查看时效，不直接调用催审、延期或改派命令 |

## 四、交互与状态

- `READY_FOR_DISPATCH`：操作"送出"，论文交百杰派单；
- 确认送出前同时校验学校账户额度并冻结批次费用快照；额度不足时保留 `READY_FOR_DISPATCH`，不创建任务，引导查看 PAGE-024；
- `UNDER_REVIEW`：显示进度（已评数量），可查看撤回申请；
- `RESULT_PROCESSING`：操作"结果"跳到 PAGE-011；
- 学校侧不直接催审、延期或改派；相关命令由百杰侧在 PAGE-007 执行；
- 撤回申请：学生发起 → 学校审批（在此页或通知中心），批准后论文回 `DRAFT`；
- 永久终止：危险操作，二次确认 + 必须填原因，不可逆。

## 五、数据来源与权限投影

- 数据来源：`GET /school-review/theses`（进度投影）、`POST /school-review/theses/{id}:confirm-dispatch`、`POST /withdrawal-requests/{id}:decide`、`POST /school-review/theses/{id}:terminate`；
- 仅本租户；可识别学生；任务进度不含专家身份（API 设计 3.3）；
- 此进度页不展示结果正文；未发布的去标识结果仅在 PAGE-011 处理，发布后由学生/导师查看。
