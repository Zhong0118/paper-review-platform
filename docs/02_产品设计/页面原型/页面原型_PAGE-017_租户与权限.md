## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 租户列表 | 编码/名称/状态/操作 | Table | 服务端分页 |
| 租户配置 | sync_mapping JSON 编辑器 | CodeEditor | 版本化（config_version） |
| 组织与批次 | 组织树、批次、资格数量、同步版本 | Tree+Table | 学校权威字段只读；按租户查看 |
| 用户/角色 | 用户列表、角色分配 | Table+Form | 角色 code + 租户 + 数据范围 + 有效期 |
| 同步状态 | 同步作业列表与详情 | Table+Drawer | 展示进度、映射/源版本和逐条失败原因；敏感载荷脱敏 |

## 四、交互与状态

- 租户停用：二次确认，禁止新业务，历史数据保留（FR-001）；
- 角色分配：学校角色必带 `tenant_id`；平台角色（system_admin/platform_reviewer/expert）不要求；
- 同步字段映射：保存递增 `config_version`，旧版本审计保留；
- 组织、批次和提交资格来自学校系统同步，在平台只读；错误应在学校系统修正后重试同步；
- 同步作业支持查看 `PENDING/RUNNING/SUCCESS/PARTIAL/FAILED`，`PARTIAL` 必须展示成功、失败和跳过数量；
- 系统管理员默认不接触论文正文/评阅内容（AC-004）。

## 五、数据来源与权限投影

- 数据来源：`/admin/tenants`、`/admin/users`、`/admin/role-assignments`、`/integrations/school/sync-jobs/{id}`；
- 仅系统管理员；默认无论文/评阅/盲审映射内容；
- 数据投影：组织、批次、资格只显示管理所需标识和同步状态，不出现论文正文、评阅内容或专家业务资料。
