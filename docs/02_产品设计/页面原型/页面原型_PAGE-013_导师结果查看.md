# PAGE-013 导师结果查看

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 导师结果查看 |
| 角色 | 导师 |
| 入口 | 导师登录后默认页 / 菜单"我的学生结果" |
| 关联 API | API-026 发布结果 |

## 二、布局线框

```text
┌───────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 导师端            通知铃  ·  用户     │
├───────────────────────────────────────────────────────┤
│ 我的学生（结果已发布）                                    │
│  筛选: 批次 (下拉)    学生 (搜索)                        │
│  ┌─────────────────────────────────────────────────┐  │
│  │ 学生       论文题目      批次      汇总分   详情   │  │
│  │ {学生一}  {题目}       2026春    {82}    [查看]   │  │
│  │ {学生二}  {题目}       2026春    {85}    [查看]   │  │
│  └─────────────────────────────────────────────────┘  │
│                                                       │
│  ── 学生结果详情 ──                                     │
│  各专家分数: {82, 85}  汇总: {83.5}   [查看获准评语]      │
│  注: 专家身份隐藏；仅已发布结果                          │
└───────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 学生列表 | 学生/论文/批次/汇总分 | Table | 服务端分页；仅本人指导的学生 |
| | 详情操作 | Button | 跳转详情 |
| 详情 | 各专家分数/汇总/获准评语 | 只读 | 专家身份隐藏；仅已发布 |

## 四、交互与状态

- 仅显示已发布结果；未发布（论文非 `COMPLETED`）不可见；
- 导师仅能查看本人学生（数据范围限定），不能看其他学生；
- 不参与送审前审批，无审批/操作按钮（只读参考）；
- 空状态：无已发布学生结果时显示引导。

## 五、数据来源与权限投影

- 数据来源：`GET /my/theses/{id}/published-result`（导师上下文限定本人学生）；
- 专家身份、未发布结果、其他学生数据均不可见；
- 导师登录与学生共用学校 SSO（Q-016 决定）。
