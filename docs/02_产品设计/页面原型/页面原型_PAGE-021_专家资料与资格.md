# PAGE-021 专家资料与资格

## 一、页面信息

| 项 | 值 |
|---|---|
| 页面 | 专家资料与资格 |
| 角色 | 专家 |
| 入口 | 专家端用户菜单“个人资料” |
| 关联 API | API-012 专家本人资料与资格 |

## 二、布局线框

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏: 百杰校审 · 专家端                    通知铃 · 用户      │
├──────────────────────────────────────────────────────────────┤
│ 个人资料                                      资格状态: {状态} │
│ ┌────────────────────────────┬───────────────────────────────┐ │
│ │ 基本信息                    │ 评审能力                       │ │
│ │ 姓名*: ______（按策略只读）  │ 学科: (受控目录)                │ │
│ │ 联系方式*: ______           │ 擅长评审领域*: [标签多选]         │ │
│ │ 单位/职称*: ______          │ 回避声明: [查看/补充本人声明]      │ │
│ └────────────────────────────┴───────────────────────────────┘ │
│ 资格材料                                                      │
│ [上传资质文件]  文件名 / 类型 / 有效期 / 审核状态 / 驳回原因     │
│ [保存资料]                                                     │
└──────────────────────────────────────────────────────────────┘
```

## 三、字段与组件

| 区 | 字段/组件 | 类型 | 约束 |
|---|---|---|---|
| 基本信息 | 姓名/联系方式/单位/职称 | Form | 仅本人；权威字段按来源只读 |
| 评审能力 | 学科/擅长领域/本人回避声明 | Select+Tag | 使用受控编码，不自由创建学科 |
| 资格材料 | 文件/类型/有效期/状态/原因 | Upload+Table | 用途 `qualification`；短时授权 |
| 操作 | 保存资料 | Button | 变更写审计；提交时防重复 |

## 四、交互与状态

- 专家只能维护本人资料，不能查看专家库中其他专家；
- 资格材料新增或重要字段变更后进入审核流程，审核结果由 PAGE-006 的百杰侧能力处理；
- 资格未通过、已过期或服务禁用时，页面明确说明对新任务指派的影响，但既有任务按服务端规则处理；
- 驳回时展示可公开的原因和重新提交入口；上传失败显示原因、进度和重试；
- 页面不展示服务学校列表、其他学校使用记录或其他专家信息。

## 五、数据来源与权限投影

- 数据来源：`GET/PATCH /experts/me`、API-012 资格材料与文件授权投影；
- 仅专家本人；百杰审核人员通过 PAGE-006 使用管理投影；
- 学校侧不可见专家真实身份、联系方式和资格文件。
