## 迁移与联调次序

迁移链为 `0031_task_extensions → 0032_review_draft_revision → 0033_abandoned_drafts → 0034_public_revision_advice`。0032 为已存在的普通评阅草稿赋初始 revision 1；0033 为已弃纯草稿保留证据且解除其活跃唯一性，有放弃标记时禁止会让草稿复活的降级；0034 只改变今后发布行的严格校验。未改写旧发布件，也未迁移开发环境。论文草稿指纹绑定当前材料版本 ID、题目、摘要、学科、关键词、校码及有序文件绑定；等值内容使用同一指纹，不主张它是单调的编辑次数。

UI 联调使用同时包含本轮迁移与接口的全新隔离场景；旧前端的无条件保存/提交会被新后端拒绝。以后若需升级共享环境，应一起安排迁移、前后端版本和浏览器重新加载。只改 Vue 模板无法修正数据库的公开快照，反之仅执行迁移也不会刷新浏览器旧代码。服务端归档、返回隐藏资源 404 和意见字段白名单均继续生效；发布白名单不等于自动保证自由文本不含身份线索。
