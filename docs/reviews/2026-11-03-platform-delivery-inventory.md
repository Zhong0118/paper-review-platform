# 论文盲审平台交付盘点

盘点日期：2026-11-03。实际分支 codex/slice-7a1-file-integrity，功能基线 c299ed9。本文核对仓库、计划和已有验收证据，未重新运行测试。“已完成”指真实模式在本地虚构数据环境验收过；旧演示页面、设计文件和软著名称不计入实现。

**现在可以做什么：** 学校能组织一次完整的单专家盲审：建批次、给学生资格、收原始和匿名PDF、送出、选派、在线评阅、发布结果，再处理异议或正式更正。平台支持多校隔离；[首批确认规模](../superpowers/specs/2026-09-22-pilot-scope-decisions.md)为 **1所学校、20篇论文以内、10名专家、2名学校管理员，每篇1名专家**。这是约定规模，不是生产实绩或容量测试结果。

## 3. 两期增强模块：目标、做法、收益与缺口

| 模块 / 本应完成什么 | 如何实现 / 实际完成 | 使用价值与例子 | 后续补充或明确不覆盖 |
|---|---|---|---|
| [E01 正式结果更正](2026-10-12-e01-validation.md)：纠正误提交并保存历史 | 专家申请→平台审批→专家提交新版→学校确认；处理期间旧发布有效，不恢复专家文件权限 | 实测学生先看80分，学校确认后才变成68分，原版保留 | 没有单独立即下架已发布结果；如需要，先定撤下和重发规则 |
| [E02 评语提交前检查](2026-10-12-e02-validation.md)：让专家核对明显问题 | 检查短评、重复长句、明确结论与分档冲突、手机号/证件格式线索；定位原文、专家确认、提交重算、保留摘要 | 改过评语不能沿用旧确认；不会自动改写正常学术批评 | **评语审核词表当前0条**。若要靠词库覆盖错别字或敏感词，先补经审核词条与误报样本；不能宣称全面纠错 |
| [E03 本人历史评语相似性](2026-10-12-e03-validation.md)：标记重复使用线索 | 排除本任务，查本人近365天最多200条有效历史；剔除模板后检查完全相同与字符片段相似，高度相似阈值0.85，不返回历史候选全文 | 专家知道哪里像、比较过多少条；无历史不会显示“质量合格” | 不是跨专家/全平台查重，不作抄袭认定。用校方认可的虚构样本先评估提示是否有用 |
| [E04 全部/近一年](2026-10-12-e04-validation.md)：统一查询口径 | 8个真实论文/评阅列表按论文创建日和上海日期回溯一个公历年；有偏好保存、刷新保持和老未结项提示 | 用户不用归档或删除旧数据就能切换视图 | 不对名录和异议待办统一隐藏；不等于数据保留/删除策略 |
| [E05 运营看板](2026-10-12-e05-validation.md)：从数量找到具体工作 | 学校/平台按当前轮次统计，点击数量看列表；学校看有效发布分数分布，平台不读评分 | 更正后分布随有效成绩更新，同一论文不重复计数 | 没有截止时间时明确“未配置”，不报逾期0；做催审前需先定义期限。无趋势预测 |
| [E06 列配置](2026-10-12-e06-validation.md)：常用表能保留个人视图 | 学校论文、专家任务、平台候选三个表格支持显隐、拖动、键盘排序、恢复默认；按身份和表格在本浏览器保存 | 调整列不影响别人；刷新保持，窄屏能在表内横向滚动 | 不是所有页面，未跨设备同步。由使用者指出下一张高频表再扩展 |
| [E07 论文匿名与敏感信息](2026-10-12-e07-validation.md)：送出前找到破盲位置 | 按PDF物理页检查姓名、学号、导师及学校字面词；文件名和元信息单列。报告绑定文件、输入与词表版本。警告需人工说明，身份命中/阻断词不能忽略 | 学校能定位后复核；材料变化需重检。标题只核对前两页文字 | 扫描件仍需人工，未做OCR、自动替换或语义标题鉴定。**学校论文词表不同于E02评语词表** |
| [E08 在线PDF处理](2026-10-12-e08-validation.md)：可安全更换草稿材料 | 学生在本人可编辑稿合并、提取、删页；禁网Docker进程限60秒/512MiB。先生成新文件和预览，再确认换版，原件保留 | 可先看页数、顺序；取消保留原材料，确认后旧检测失效 | 提取每次生成一个片段；不是任意已提交材料编辑、批量分册、格式检测或Word批注 |
| [E09 专家档案与导入](2026-10-12-e09-validation.md)：可核对地更新已有专家 | 维护单位、职称、省份、博/硕导三态、方向、关键词和来源；CSV先预览差异，再限时由本人确认，版本冲突整批拒绝，受保护状态不能被导入改写 | 不把“未知”当“否”，旧表格不能覆盖别人刚维护的资料 | 是人工维护/导入，没有自动抓高校网站、周期同步、实名认证或证书核验 |
| [E10 可解释专家推荐](2026-10-12-e10-validation.md)：帮平台选人，不代替责任人派单 | 方向命中标题/摘要每项3分、最多15；关键词交集每项2分、最多10。可派者优先、显示计分标签；确认前重查资格、回避和档案版本 | 实测19分回避者禁选，0分但符合条件的旧档案仍可人工选派。规则分不是概率 | 不分析PDF全文、不自动派单或等待推送，不对学校公开实名候选 |
