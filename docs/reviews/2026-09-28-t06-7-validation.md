## 已实现

`0015_rls_children` 将 `thesis_version_files`、`anonymization_checks`、`review_drafts`、`review_result_versions`、`result_publications` 五表启用并强制 RLS，累计 28/28 表。旧 link 在升级前逐行核对版本与文件的论文、租户、purpose；冲突拒绝。link 新增论文/租户归属并回填，两条复合 FK 阻止跨校、同校错论文、错 purpose 挂接；学生删草稿可删除本人 link，旧孤儿文件不能挂到新论文。专家只能读当前 `IN_REVIEW` 任务的匿名 link，原文 link 不可见；任务提交后 link 立即失去可见性。

正式评阅结果新增轮次/租户归属并从任务回填，复合 FK 保证其与任务一致。专家结果写入在已锁任务 `IN_REVIEW` 时先 flush，随后标记 `SUBMITTED`；这没有更换锁对象或锁顺序，并阻止普通专家在提交后直接改正式分数。学生/导师读取已发布结果改为从本人可见汇总的任务 ID、轮次和租户读取当前结果，不读取专家任务行；学校发布前原任务集合验证仍保留。此归属列是原 JSONB 任务 ID 设计的必要补强：即使已发布汇总被写入外校任务 ID，学生也不能读出外校结果。
