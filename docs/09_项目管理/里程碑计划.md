# 里程碑计划

## 1. 编制说明

里程碑按业务闭环划分，与 `docs/09_项目管理/项目管理.md` 第 4 节建议增量对齐，并映射到 `docs/09_项目管理/实施计划.md` 的任务。里程碑不承诺具体日期，日期在团队与试点学校确定后填充。每个里程碑出口必须形成可运行、可验证的结果，并提交对应 AC 证据。

| 里程碑 | 名称 | 覆盖闭环/任务 | 出口条件 | 关联验收 | 状态 |
|---|---|---|---|---|---|
| M0 | 基础工程与质量门禁 | C0 / T-001—T-004 | 本地可启动、三依赖连通、CI 门禁全绿、错误码协议统一 | NFR-009/010/012 | 待启动 |
| M1 | 用户、组织与权限 | C1 / T-005—T-008 | 多租户、学校同步、五角色权限、RLS 隔离全部通过 | AC-001—004；TC-001—003 | 待启动 |
| M2 | 论文提交与材料门禁 | C2、C3 / T-009—T-013 | 学生可提交原件/匿名件，匿名检测与人工确认阻断送审 | AC-005—007、011；TC-004—007 | 待启动 |
| M3 | 专家与派单 | C4、C5、C6 / T-014—T-018 | 专家库、擅长领域、回避检查、轮次与任务创建、接单超时 | AC-010—015；TC-009—012 | 待启动 |
| M4 | 在线评阅与结果 | C7、C8 / T-019—T-023 | 专家接拒、草稿、最终提交、更正、催审、改派、补审 | AC-012—019；TC-010—016 | 待启动 |
| M5 | 汇总发布与异议 | C9、C10 / T-024—T-027 | 汇总、冲突、发布、学生/导师查看、异议处理 | AC-018—021；TC-015—018 | 待启动 |
| M6 | 通知、审计、统计 | C11、C12、C13 / T-028—T-031 | 通知去重重试、审计全链路、基础统计口径一致 | AC-024、025；TC-020、021 | 待启动 |
| M7 | 导出、费用与结算 | C14、C15 / T-037、T-032—T-033 | 异步导出、费用入账、提现申请、人工付款回填 | AC-022、023、026；TC-019、022 | 待启动 |
| M8 | 部署运维与上线 | C16 / T-034—T-036 | 三环境部署、联合备份恢复演练、监控告警、发布准入通过 | AC-027；TC-023 | 待启动 |

## 2. 里程碑依赖

- M1 依赖 M0；M2 依赖 M1；M3 依赖 M2 与 M1；M4 依赖 M3；M5 依赖 M4；M6 依赖 M5（统计数据）与 M3 起的事件源；M7 依赖 M4（费用来源）与 M5（导出数据）；M8 依赖 M0—M7 全部通过发布准入。
- C4/C5（专家、匹配与回避）可在 M1 后与 M2 并行准备，但派单（M3）必须等 M2 的匿名门禁完成。

## 3. 里程碑准入规则

- 每个里程碑完成前必须运行该里程碑全部任务的单元、集成、契约与相关 E2E 测试；
- 跨租户、双盲、审计、幂等、并发相关 AC 必须提供真实测试证据，不得以文档声明代替；
- 安全与测试不推迟到最后一个里程碑，随里程碑逐项落地。

## 4. 更新时机

- 试点学校与团队确定后填充每个里程碑的目标日期与负责人；
- 任一任务范围变更时同步更新 `实施计划.md`、`Sprint计划.md` 与本文件。
