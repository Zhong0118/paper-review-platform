# 风险清单

## 1. 编制说明

风险等级：P0 阻塞交付必须处理；P1 影响质量/进度需主动管理；P2 关注。应对措施与实施计划任务挂钩。风险清单随里程碑评审更新。

## 3. 风险监控

- 每个里程碑评审更新风险状态（待执行/缓解中/已关闭/新增）；
- P0 风险未关闭不得进入对应里程碑发布准入；
- 新增风险登记到 `docs/10_审查与决策/问题与决策记录.md` 并同步本清单。
