# Sprint 计划

## 1. 编制说明

Sprint 按可独立验收的迭代拆分，每个 Sprint 输出可运行、可验证的结果。Sprint 默认两周一次评审；周期在团队确定后调整。每个 Sprint 必须包含后端、前端、数据、权限、测试、运维和文档，不把安全或测试统一推迟到最后。

| Sprint | 目标 | 任务 | 里程碑 | 完成时交付 |
|---|---|---|---|---|
| S1 | 基础工程与质量门禁 | T-001、T-002、T-003、T-004 | M0 | 可启动的模块化单体骨架、健康检查、统一错误码、CI 门禁 |
| S2 | 租户与同步 | T-005、T-006 | M1 | 租户管理、学校同步与字段映射、同步幂等与版本化 |
| S3 | 五角色与隔离 | T-007、T-008 | M1 | 五角色授权、RLS 隔离、跨租户越权测试通过 |
| S4 | 论文提交 | T-009、T-010、T-011 | M2 | 草稿、文件上传校验、提交与派单前撤回 |
| S5 | 匿名化门禁 | T-012、T-013 | M2 | 匿名检测、材料确认、阻断与退回 |
| S6 | 专家库与匹配 | T-014、T-015、T-016 | M3 | 专家档案/账号、擅长领域、候选检索与回避 |
| S7 | 送审任务 | T-017、T-018 | M3 | 轮次与任务创建、并发控制、接单超时扫描 |
| S8 | 专家评阅 | T-019、T-020、T-021 | M4 | 接拒、草稿、最终提交锁定、更正版本 |
| S9 | 催审与改派 | T-022、T-023 | M4 | 催审延期、改派补审、事件历史保留 |
| S10 | 汇总发布 | T-024、T-025、T-026 | M5 | 汇总冲突、发布、学生/导师查看 |
| S11 | 异议 | T-027 | M5 | 异议登记、处理、结论回填 |
| S12 | 通知 | T-028、T-029 | M6 | 站内+外部通知、模板版本、去重重试 |
| S13 | 审计与统计 | T-030、T-031 | M6 | 审计全链路、基础进度/运营指标 |
| S14 | 导出与费用结算 | T-037、T-032、T-033 | M7 | 异步导出、费用入账、提现、人工付款回填 |
| S15 | 部署运维 | T-034、T-035、T-036 | M8 | 三环境部署、备份恢复演练、监控告警、发布准入 |

## 2. Sprint 依赖

S1→S2→S3→S4→S5→S7→S8→S10→S11；S6 与 S4/S5 并行；S9 依赖 S8；S12 依赖 S3 起（通知接入各事件）；S13 依赖 S10；S14 依赖 S8（费用）与 S10（导出）；S15 依赖 S1—S14 全部通过发布准入。

## 3. Sprint 评审与回滚

- 每个 Sprint 结束评审会：对照实施计划对应任务的验收标准逐项确认，提供 AC/TC 证据；
- 未通过项回到对应任务，不进入下一 Sprint；
- 单个任务回滚方式见 `docs/09_项目管理/实施计划.md` 对应任务"回滚"；跨 Sprint 回滚到上一里程碑镜像。

## 4. 更新时机

- 里程碑日期与团队排期确定后，为每个 Sprint 填充起止日期和负责人；
- 任务拆分调整时同步更新 `实施计划.md` 与 `里程碑计划.md`。
