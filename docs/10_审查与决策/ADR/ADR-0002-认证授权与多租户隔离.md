# ADR-0002 认证授权与多租户隔离

## 状态

方向已由用户确认（Q-001、Q-003、Q-010、Q-014）；认证协议细节需在学校接口明确后补充。2026-08-04 补充：百杰运营侧可查看学生与专家身份以支撑派单、进度和费用管理（Q-014），不改变专家与作者/导师之间的双盲隔离。

## 背景与问题

平台由百杰运营并服务多所学校。学校业务数据必须隔离，平台专家库需要跨校复用，同时双盲要求不能简单等同于管理员全权读取。

## 候选方案

- A：每校独立数据库。
- B：共享数据库、共享 Schema，仅应用层过滤。
- C：共享数据库、共享 Schema，应用过滤与 PostgreSQL RLS 双重隔离。

## 选定方案

选择 C。服务端基于已认证主体、五类核心角色、租户和组织数据范围授权。学校身份和资格由学校系统提供；学生在平台完成论文提交。平台共享专家表不属于单一租户，专家任务等业务记录必须归属租户。

## 理由与影响

方案兼顾多校运营成本和纵深防御。代价是所有业务表、连接上下文、迁移、后台任务和测试都必须正确处理租户。平台管理员默认不获得业务内容或盲审映射权限。

## 后续约束

任何新表和接口必须明确平台级或租户级归属。跨租户维护只能通过专用主体、最小范围和审计执行。P0 必须有真实 RLS 集成测试和跨租户对象/文件/导出测试。
