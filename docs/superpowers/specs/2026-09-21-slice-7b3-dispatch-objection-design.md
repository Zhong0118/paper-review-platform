# 7B-3 拒绝再派入口与当前异议

- 平台派单队列新增 allowed_actions；仅当前版本有效 CREATED/ACTIVE 轮次且无 INVITED/IN_REVIEW/SUBMITTED 席位占用时返回 ASSIGN_EXPERT。全拒绝可再派；未确认送出、失效轮次或已有在途/正式结果不可派。真正 assign 继续执行论文锁及原有回避/单专家检查。
- 真实派单页按服务端动作展示待派列表及数量，不用 UNDER_REVIEW 推断不能派；成功后刷新清理旧候选/选择并允许下一篇。候选加载失败不可派，晚到响应不能串篇；不匹配/回避/不可用专家不能选为可派对象。不新增取消旧任务的 reassign API。
- 学生异议列表顺序明确为未办结优先、created_at 降序、id 降序稳定打破同时间。序列化增加 created_at；保留历史记录。前端使用此契约展示当前异议及提交时间；空列表才视为没有异议，异常显示错误并禁止误开重复申请。
- 结果未发布的 404 保留正常空态；已发布后的异议读取失败不得吞掉。切换论文立即清空旧数据，迟到请求不得覆盖当前记录。
- 无迁移/新依赖，不改正式评分或论文阶段，不扩展多专家与运营功能。
- 验证真实拒绝→可派→另一专家新任务→不可重复派；异议办结→新建→当前未办结→再次办结历史排序；前端真实模式、异常/迟到响应回归；全套测试/构建及独立审查。
