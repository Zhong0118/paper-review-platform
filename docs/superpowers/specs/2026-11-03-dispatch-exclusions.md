# 11 平台派单：解释无候选

目标：平台审核员在已选论文的候选请求成功后，能区分「没有返回有效专家档案」和「有专家，但全部不可派/改派」，知道应核对什么。学校、学生、导师、专家不新增入口。

依据同一份受限候选接口的返回值。只要有人能执行当前派单/改派，就不展示无候选提示；零分不是被排除。无可操作人选时展示总人数与排除原因，各原因对同一专家只计一次，不同原因可以重叠；不泄露回避涉及的具体人或学校，不把未进入候选的账号计算在内。没有候选记录时提示平台核对专家档案和账号，不推断是全库无人、全部回避或学校设置错误。旧客户端/测试契约中的单项限制沿用既有显示逻辑，不另写派单规则。

请求进行中、已清空论文、请求失败和切换论文后的过期响应，不得当成当前论文的无候选结果。显示/隐藏不可选行的列表开关不影响计数。只读，无新 API、数据库迁移、权限或派单状态变化，演示模式不显示。
