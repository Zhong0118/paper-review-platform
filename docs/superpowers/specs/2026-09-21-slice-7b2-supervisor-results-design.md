# 7B-2 导师结果入口与真实评审建议

依据 CURRENT 与审查 B4/B7，延续用户已授权的逐批修复，不新增运营功能。

- 增加 GET /api/v1/supervisor/theses/published，仅导师角色；tenant 来自 token。列表仅含当前租户、该导师有效 SUPERVISOR membership 所指导、同论文批次资格关联的 COMPLETED 论文；返回 id/title/student_name，不返回专家身份或文件。按创建时间与 id 确定排序，页面允许选择论文。
- 既有 /my/theses/{id}/published-result 的导师权限共用相同关联筛选。跨租户、无关联、关联失效、未发布返回 RESOURCE_NOT_FOUND。多批次资格和同一导师的多校 membership 不得造成 scalar 多行错误，也不得取错批次授权。
- 学生结果入口保持现有接口与行为；不扩大为导师可读学生草稿或原文。
- 导师页改用专属列表；区分加载中、真实空态、列表/详情失败；错误提供重试，不吞成“尚未发布”。选择变化立即移除旧结果，晚到的旧请求不能覆盖新选择。
- 学校/导师汇总分使用服务端 summary_total/total；建议原样使用当前单专家 recommendation，不按分数推导，不默认“建议通过”；空建议显示“未填写评审建议”。无结果时不显示虚构 0 分/通过结论。
- 学校切换论文时清空旧结果，加载失败不可发布；只有已加载选中论文的有效结果且 allowed_actions 含 PUBLISH_RESULT 才能发布。发布请求固定论文 id 与版本，发布期间禁止切换；失败显示错误并可重试。
- 不改变发布规则、正式评分、专家匿名化或演示服务。PDF 常用浏览器渲染待补验项保持。
- 回归：导师列表发布前/后、无关联/失效、跨租户、多批次/多校；真实“不通过”/空建议及服务端分数显示；错误空态、多论文选择/迟到响应、发布请求正确绑定。独立测试库，全套前后端与构建。
