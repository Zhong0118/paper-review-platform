# 15、18、16 已批准的运营规则

15：学校按批次配置两个独立的正整数自然日数，可留空，无默认值。学校在草稿或开放批次修改，只影响后续派单；已有任务冻结邀请截止和评阅天数。按北京时间起算，到第 N 个自然日的同一时刻截止，达到截止即标记；晚接仍可接、晚交仍可交。改派产生新的邀请和计时。学校只看本校匿名任务期限；平台和专家分别看获准的任务。不猜测回填旧数据，不自动撤单、通知或扣费。

18：平台候选中列出当前有效轮次的待接单、评阅中和合计。排除取消、拒绝、提交、失效轮次；计数跨该专家所服务的学校，不向学校开放。仅供参考，不影响分数、排序或可派资格。

16：本人在已接且有评阅截止的任务中申请新的具体截止时间，必须晚于现期限和当前时间，并填写理由。允许已逾期申请；同时最多一条待审，驳回后可重提，最多批准一次。平台填写审批理由，批准仅延长评阅截止。原期限、目标期限、申请和审批理由/时间保留。学校仅获有效截止，不获得专家身份和申请内容。待审任务一旦终止、改派或提交，不允许审批，不让待审记录成为可处理事项。申请、决定与任务变更共用论文→任务锁；数据库限制重复申请/审批。接口不接收租户、操作者身份。
