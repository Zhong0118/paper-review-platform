# 学校试用补充：01、02、06、13
范围：在真实模式和已有角色权限内增加四项；不增加状态、表或生产依赖服务。
- 01：本人可编辑草稿根据原批次资格、服务端开放目录和当前编辑内容，一次展示全部缺项。未上传的本地文件区分待上传；不以预检代替服务端提交校验。原资格缺失联系学校；暂停只限制建新稿。
- 02：复用已绑定匿名文件的页码预览；支持从每条有物理页的命中打开、上/下一处、同页多处与页码说明，宽屏并排，窄屏上下。非页码命中不能伪造页码；失效后释放预览。
- 06：仅本校学校审核员从有效发布快照下载真正的 PDF。列出匿名编号、发布日期（上海日期）、发布序号、六维、总分、结论和已发布意见。更正待确认仍读旧快照，未发布不可导出。无专家账号、真实姓名字段、文件路径或内部备注；不自行改写已发布评语。
- 13：学校在本校批次页打开只读清单。列出未发布且未终止的论文、未结异议、待学校确认的更正，分项计数且可逐项打开。不受近一年偏好限制；不阻止现行归档，不变更数据。
