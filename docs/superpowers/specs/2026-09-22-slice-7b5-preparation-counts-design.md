# 7B-5 学校准备页真实检测统计

修复审查 B11。真实模式以学校列表接口返回的每篇论文最近一次检测 anonymization.auto_conclusion 为唯一依据，对 PASS/REVIEW_REQUIRED/FAIL 分别计数；null/未知不归入任何类。不从论文阶段推断检测结果，不因人工审核结论改写自动分类，搜索仅筛选表格。显示统计范围说明，并用“需人工复核”替换“待人工复核”避免声称仍有待办。

初次加载未完成、列表失败或命令后的刷新失败时隐藏旧统计/表格/操作，显示加载或错误和重试入口；只有成功读取空列表显示 0/0/0。审核、送出、终止后的刷新共享同一装载函数，同步更新表格和统计。保留演示模式；不改后端、数据库、scenarioService 或扩展统计模块。

先写失败回归，再最小实现；验证计数、空态、错误重试、搜索范围及操作后刷新，并跑前端全套、类型检查、真实模式构建。

实现前的“当前版本”假设已在独立复核后纠正：_latest_check 查询论文全部版本最新记录。沿用现有接口口径并明确告知“可能来自退回前旧版本，不代表当前版本已通过”；不擅自更改影响退回原因和审核流程的后端检测投影。
