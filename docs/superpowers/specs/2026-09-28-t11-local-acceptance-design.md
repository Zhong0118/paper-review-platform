# T11-A：六角色本地业务验收与交付封板

状态：本地 T11-A1/A2 已验证，实际试点放行 T11-B1 仍待环境；[候选版本交接](../../reviews/2026-09-28-local-pilot-release-candidate.md)。依赖 T07、T08、T09-A、T10-A。本项目标是用真实页面和真实后端证明一个可操作的虚构试点闭环；保留 T03 隔离服务，不新造演示后台。

## 验收方式

使用 acceptance_server operations 场景与 VITE_DEMO_MODE=false 前端；逐角色独立浏览器上下文，避免 localStorage 登录串角色。所有论文为虚构 PDF；角色凭据仅通过本地临时渠道使用，不放报告/截图。每一步记录页面/动作、可见结果、独立读回证据及 PASS/FAIL/NOT RUN。

没有 browser 工具或 PDF 正文无法显示，就标对应项 NOT RUN；不能以 HTTP 200 代替浏览器正文可读。已有浏览器工具优先；不为本次验收自建自动化平台。自动化 HTTP 可以补负例，但必须单列。

| 场景 | 浏览器必须观察 | 独立核对 |
|---|---|---|
| 系统初始化 | 学校/学校管理员操作成功；刷新仍存在 | API/库 school、STAFF 与角色一致 |
| 学校准备 | 批次、学生/导师成员和资格可创建/更改 | 刷新与关系 ID 一致；无跨校显示 |
| 学生材料 | 创建、上传原文/匿名 PDF、提交 | 冻结版本、两种文件 hash/归属 |
| 学校审核 | 匿名复核/确认送出 | 新轮次规则 v1、当前版本一致 |
| 平台专家运营 | 创建、批准、暂停/恢复、两类回避 | 非 seed 专家可登录；无费用/统计假值 |
| 平台派单 | 不合格/回避不可选；选可用专家派单 | 直接 API 也拒绝不合格 ID，单席位 |
| 专家邀请 | 接受后打开对应任务 | 标题匿名、其他专家无权 |
| 专家评审 | PDF 正文可读；六维规则可见；草稿刷新恢复；提交后锁定 | 正式分数与轮次快照一致，旧写请求失败 |
| 学校发布 | 查看化名/档位、发布后页面更新 | 发布前学生/导师不可读，发布后可读 |
| 学生/导师结果 | 各自可见范围、化名、总分与档位 | 无专家真实姓名/他校论文 |
| 异议闭环 | 学生提交、学校处理办结 | 并发/重复未办结负例沿用现有测试 |
| 异常流程 | 专家拒绝再派、在途改派、学校终止、学生撤回重提 | 原任务不能延迟提交，旧令牌/旧候选拒绝 |
| 冲突与空态 | 两页面旧 version 写入409、网络失败可重试、无数据不伪造 | 不本地伪造成功，不自动重放新 version |
| 权限负例 | 换角色直接开路由/链接拒绝 | 专家原文/外校/系统正文拒绝；日志无凭据 |

最后两行可在独立负例上下文执行，避免破坏主链数据。历史页面测试与本次浏览器记录分开；所有缺陷登记“步骤→预期→实际→失败用例→最小修复→复验”，不扩展收费、通知、多个专家。

## 封板标准

上述必需浏览器行无 FAIL/NOT RUN、后端/前端全量与类型/真实构建通过、日志去敏/配置门禁/T10本地恢复有对应记录，才标 T11-A 本地完成。Hosted CI 未跑仍注明；不因此宣称 T11 总体放行。若有高优先级缺陷，修复后重跑受影响路径；封板前统一检查一次，之后没有实现变更不重复跑全套。

最终交付包列出 11 项顶层状态及各子项、实际代码/迁移版本、测试命令/退出码、浏览器矩阵、恢复记录、已知限制和部署 B 阶段输入。检查 diff/未跟踪文件，准备去敏文件清单；没有提交授权不 commit、不上传。完整本地交付仍允许正式发布被环境/数据条件阻断。
