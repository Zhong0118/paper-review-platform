# 百杰运营与专家端交互闭环设计

## 1. 背景与结论

学生端闭环（Task 1–8）已完成：材料提交、学校审核、结果查看与异议。本阶段补齐平台运营主链路的另一半——**百杰运营（platform_reviewer）与专家（expert）**，二者是送审闭环的运转核心：运营负责专家库、派单、催审、改派、更正审批与结算；专家承接真实评阅闭环，完成后才产生结果。

采用与学生端一致的"**真实业务操作 + 独立演示状态切换**"方案：两个角色各自的业务页面只提供本人依法可执行的动作；跨角色推进（如运营派单后专家才收到邀请）由共享的持久化场景状态驱动，演示控制器提供运营侧和专家侧的独立场景入口。所有页面共用现有 `ScenarioService` 状态模型并扩展专家任务与运营队列投影。

**单专家评审已确定**（Q-017、演示批次规则快照）：一篇论文同一时间只能存在一个当前有效专家任务；拒绝、超时或撤回后才允许改派。

## 2. 范围

### 2.1 本轮包含

**百杰运营端：**
- PAGE-006 平台专家库：专家档案、资格审核、暂停/恢复、回避管理、历史任务；
- PAGE-007 送审运营台：十条运营队列、派单详情（专业/关键词/论文类型/回避/学校要求）、候选专家与可解释匹配、指派/改派/催审/延期；
- PAGE-020 评阅更正审批：更正申请列表与审批（批准生成新版本 / 驳回留原因）；
- PAGE-022 结算处理工作台：提现审核、线下付款回填（财务职能权限视图）。

**专家端：**
- PAGE-008 专家任务列表：待接受 / 评阅中 / 已完成三 Tab（另含已拒绝、已撤销、需要更正）；
- PAGE-009 专家接单详情：匿名概要、接受/拒绝（必填原因）、截止时间、专业匹配说明；
- PAGE-010 在线评阅工作台：六维评分模板、总体评价/主要问题/修改建议、草稿自动保存、暂存退出、提交前完整性检查、二次确认、提交后只读、申请更正；
- PAGE-021 专家资料与资格：本人资料、专业方向维护、资格材料；
- PAGE-014 提现与结算：本人账户、流水、提现申请；
- PAGE-015 两角色的消息通知（沿用学生端通知组件，按角色隔离）。

### 2.2 本轮不包含

- 真实文件上传、PDF 解析、匿名线索检测、真实消息发送、数据库或支付；
- 自动专家推荐、自动代付、运营看板（P1）；
- 学校侧、系统管理员的角色页面改造；
- 破盲或任何身份映射功能；
- 多专家同轮（平台仍支持学校/批次配置，但演示批次固定单专家）。

页面必须用明确文案说明演示数据边界，不得把本地演示状态描述成后端已完成。

**百杰运营端**（AdminLayout，左侧导航）：

4. 结算处理（PAGE-022）；
5. 消息通知（PAGE-015）。

**专家端**（PortalLayout）：
1. 我的任务（PAGE-008，默认页）；

## 4. 领域模型与状态

### 4.1 专家任务状态（复用正式文档 §4.2，唯一枚举）

`INVITED`（待接受）→ `IN_REVIEW`（评阅中，可带 overdue 标记）→ `SUBMITTED`（最终提交锁定，终态）；`REJECTED`（拒绝留原因，终态）；`ACCEPT_TIMEOUT`（接单超时，终态）；`CANCELLED`（撤回/改派关闭，终态）。

**约束：**
- `overdue` 是布尔时限属性，不是独立状态；
- 改派 = 原任务 `CANCELLED` + 同轮新任务；论文版本变化/正式复核才新建轮次；
- 单专家评审下，一篇论文同一时间至多一个非终态任务（`INVITED`/`IN_REVIEW`）。

### 4.2 送审运营队列（PAGE-007 十条）

| 队列 | 含义 | 判定依据 |
|---|---|---|
| 待匹配 | 已送出、尚未选择候选 | `READY_FOR_DISPATCH` 且无候选 |
| 待派单 | 已选候选、未创建任务 | 有候选未指派 |
| 专家待接受 | 任务 `INVITED` | 任务状态 |
| 已拒绝待改派 | 任务 `REJECTED` | 任务状态 |
| 邀请超时 | 任务 `ACCEPT_TIMEOUT` | 任务状态 |
| 评阅中 | 任务 `IN_REVIEW` | 任务状态 |
| 即将逾期 | `IN_REVIEW` 且临近期限 | 时限属性 |
| 已逾期 | `IN_REVIEW` 且 overdue | 时限属性 |
| 更正处理中 | 存在未决更正申请 | 更正申请状态 |
| 已完成 | 结果发布 | 论文阶段 `COMPLETED` |

队列是运营分组视图，不改变论文宏观状态。

### 4.3 专家档案（PAGE-006 字段，本轮演示投影）

| 字段 | 类型 | 说明 |
|---|---|---|
| 姓名 / 所属单位 / 职称 | 文本 | 运营可见身份（Q-014） |
| 专业代码与名称 | 受控目录 | 复用学生端 184 条目专业目录 |
| 研究方向 Tags | 标签（≤8） | 匹配关键词 |
| 可评论文类型 | 多选 | 演示：学术型/应用型 |
| 资格状态 | 通过/审核中/驳回 | 驳回需理由 |
| 服务状态 | 可用/禁用 | 禁用后不可新指派，既有任务不受影响 |
| 回避学校 | 列表 | 命中禁止指派 |
| 当前负载 | 数字 | 活跃任务数 |
| 历史完成数 / 逾期率 / 平均完成时间 / 历史接受率 | 数字 | 候选排序依据 |
| 评阅质量记录 | 摘要 | 更正次数等 |
| 费用标准 | 金额 | 任务费用 |
| 收款信息状态 | 已绑定/待绑定 | 脱敏展示 |

### 4.4 评阅模板（六维，版本化快照非硬编码）

演示批次快照（合计 100 分，页面按模板数据动态渲染，不得写死）：

| 维度 | 分值 | 说明 |
|---|---|---|
| 选题价值 | 15 | 问题意义与研究价值 |
| 文献与理论基础 | 15 | 综述充分性与理论依据 |
| 研究设计与方法 | 20 | 方案合理性与方法严谨性 |
| 研究内容与创新 | 25 | 工作量与创新贡献 |
| 写作规范 | 10 | 结构与规范 |
| 综合学术水平 | 15 | 整体学术水准 |

每维含：分值、评分说明、可选维度评价。另有总体评价、主要问题、修改建议、评审结论（建议通过/建议修改/不通过）。

### 4.5 更正申请与提现状态（复用正式文档枚举）

- 更正申请：`PENDING` → 批准（生成新评阅版本，旧版本只读保留）/ 驳回（留原因）；
- 提现申请：`SUBMITTED` → `REVIEWING` → `PAID`（线下回填）/ `REJECTED`（解除冻结）/ `REVERSED`（冲正留痕）。

## 5. 页面设计

### 5.1 PAGE-006 平台专家库

- 顶部统计卡：专家总数 / 可派 / 待审资格 / 即将到期 / 已停用；
- 筛选行：研究方向、资格状态、服务状态、关键字；`[查询] [重置]`；
- 工具栏：`[新增专家] [批量导入（演示占位）]`；
- 列表列：姓名/单位/职称/专业与研究方向 Tags/资格/服务状态/当前负载/历史接受率/按时完成率/操作；
- 详情抽屉（Tab）：基本资料 / 资格与材料 / 回避管理 / 历史任务 / 费用摘要 / 操作日志；
- 操作：编辑、资格审核（通过/驳回+理由）、暂停接单、恢复、设置专业与关键词、设置回避关系、查看历史任务、指派论文（跳运营台预填候选）；
- 二次确认：暂停/恢复/驳回；重要变更写审计；
- 移动端：列表卡片化（复用学生端断点）。

### 5.2 PAGE-007 送审运营台

- 队列区：十条队列 Tab + 各队列计数统计；
- 待派列表列：匿名论文号 / 送审方向 / 学校 / 状态 / 操作；
- 派单详情面板：
  - 论文信息：专业代码与名称、关键词 Tags、论文类型、回避规则、学校要求；
  - 候选专家表：复选框 + 姓名/单位/职称/专业/研究方向 Tags/关键词命中/回避命中（禁选+原因）/当前负载/历史接受率/平均完成时间/费用标准；
  - 匹配原因：每行展示"关键词命中 + 历史质量"可解释说明；
- 操作行：`[指派选中专家]`（二次确认 + 防重复）`[改派]` `[催审]` `[延期]`；
- 单专家约束：只能选择 1 位；指派成功后该论文移出待派队列进入"专家待接受"；
- 改派流程：原任务关闭（`CANCELLED`），同轮新建，保留历史。

### 5.3 PAGE-020 评阅更正审批

- 列表：申请号 / 专家 / 匿名论文号 / 申请时间 / 状态 / 操作；筛选：状态、专家、时间范围；
- 详情：原评阅版本（只读 Diff）/ 更正原因 / 拟更正差异 / 证据；审核意见（必填）；
- 操作：`[驳回]`（必填原因）`[批准并生成新版本]`（二次确认）；
- 若原结果已发布，提示影响范围；批准后新旧版本均保留。

### 5.4 PAGE-022 结算处理工作台

- 列表：申请号 / 专家 / 金额 / 申请时间 / 状态 / 操作；筛选：状态、专家、时间；
- 详情：可提现依据 / 冻结流水 / 收款信息（默认脱敏，完整查看需重认证+审计）/ 历史处理记录；
- 操作：`[驳回]`（解除冻结）`[审核通过]`（→ REVIEWING，二次确认）`[回填付款结果]`（线下成功/失败 + 凭证号，二次确认+幂等）。

### 5.5 PAGE-008 专家任务列表

- 三主 Tab：待接受 / 评阅中 / 已完成；辅助 Tab：已拒绝 / 已撤销 / 需要更正；
- 统计行：各 Tab 计数；
- 列表列：任务状态 Tag / 匿名任务编号 / 匿名题目 / 送审方向 / 接单截止 / 评阅截止 / 费用 / 操作；
- 操作：`INVITED → [接受]`；`IN_REVIEW → [继续评阅]`（逾期附加红色警告 Tag，仍可进入）；`SUBMITTED → [查看]`（只读）；有更正申请 → `[需要更正]` 标记；
- 仅本人任务；不出现学生/导师身份、其他专家评语、原始版。

### 5.6 PAGE-009 专家接单详情

- 匿名概要：匿名题目、摘要（匿名化）、送审方向、专业匹配说明、评阅截止（绝对时间）、评审费用（含说明）、评审模板说明；
- 提示：接单前仅展示匿名基本信息，不接受查看完整论文；
- 拒绝：原因下拉（方向不符/时间不足/利益冲突/其他+说明），必填；
- 操作：`[拒绝]`（必填原因）`[接受并开始评阅]`（二次确认）→ 进入 `IN_REVIEW` 并跳转工作台。

### 5.7 PAGE-010 在线评阅工作台

- 双栏（桌面）/上下（移动 ≤1000px）：
  - 左栏匿名论文阅读区：匿名题目/摘要/匿名版文件（只读，不提供下载）；
  - 右栏评阅表单：六维评分（每维分值/评分说明/可选评价）、总体评价（必填）、主要问题、修改建议、评审结论；
  - 实时总分与完整性检查（缺项/越界提示，字段级错误）；
- 操作区：`[保存草稿]`（自动保存指示）`[暂存退出]` `[最终提交]`（二次确认 + 防重复提交，提交后整页只读锁定）；
- 逾期任务：顶部红色逾期警告，仍可保存与提交；
- 提交后：只读视图 + `[申请更正]`（填写原因，提交后原版本保留）；
- 页面顶部显示任务状态与截止时间；仅本人有效任务。

### 5.8 PAGE-021 专家资料与资格

- 基本信息：姓名（按策略只读）/ 联系方式 / 单位 / 职称；
- 评审能力：学科（受控目录）、擅长评审领域 Tags（≤8）、可评论文类型；
- 回避声明：本人回避声明补充（查看/填写）；
- 资格材料：上传资质文件（文件名/类型/有效期/审核状态/驳回原因）、重新提交入口；
- `[保存资料]`；变更写审计；
- 仅本人资料，不展示其他专家、服务学校列表或其他学校使用记录。

### 5.9 PAGE-014 提现与结算

- 我的账户：可提现余额 / 冻结金额（来自流水汇总，只读）；
- 申请提现：金额输入（≤可提现，必填）+ `[提交申请]`（二次确认）；
- 提现记录：申请时间 / 金额 / 状态 / 付款时间 / 备注；
- 费用流水：有效评阅任务入账记录（只读、可审计、只追加）；
- 审核驳回展示可公开原因；不自动调用支付。

### 5.10 消息通知（PAGE-015 两角色）

- 沿用学生端 `StudentNotificationList`，按 recipientRole 隔离（`platform_reviewer` / `expert`）；
- 事件：接单邀请（`TASK_INVITED`）、任务接受（`TASK_ACCEPTED`）、拒绝/超时触发改派（`TASK_REJECTED`/`TASK_TIMEOUT`）、催审提醒（`REVIEW_REMINDER`）、更正审批结果（`CORRECTION_DECIDED`）、提现结果（`WITHDRAWAL_DECIDED`）；
- 未读/全部已读/跳转关联页面（复用学生端组件与路由模式）。

## 6. 服务接口（演示实现）

`ScenarioService` 扩展（保持现有签名风格，返回不可变快照）：

| 方法 | 用途 |
|---|---|
| `listExpertProfiles(query?)` | 专家库列表（运营） |
| `createExpertProfile(input)` / `updateExpertProfile(id, patch)` | 新增/编辑（运营） |
| `setExpertServiceStatus(id, status, reason)` | 暂停/恢复（运营，二次确认） |
| `reviewExpertQualification(id, decision, reason)` | 资格审核（运营） |
| `listExpertMatches(thesisId)` | 候选专家 + 匹配原因（运营） |
| `assignExpertToThesis(thesisId, expertId)` | 指派（单专家，二次确认） |
| `reassignExpertTask(taskId, expertId, reason)` | 改派（原任务 CANCELLED） |
| `remindExpertTask(taskId)` / `extendExpertTask(taskId, days)` | 催审/延期 |
| `listCorrectionRequests()` / `decideCorrection(id, decision, reason)` | 更正审批 |
| `listWithdrawals()` / `reviewWithdrawal(id, decision, reason)` / `recordWithdrawalPayment(id, result, voucher)` | 结算处理 |
| `listExpertTasks(query?)`（已有）扩展 overdue/fee | 任务列表 |
| `acceptExpertTask(id)` / `rejectExpertTask(id, reason)` | 接单/拒绝 |
| `saveReviewDraft` / `submitFinalReview`（已有）扩展六维 | 评阅 |
| `requestCorrection(taskId, reason)` | 申请更正 |
| `getExpertAccount` / `listExpertLedger` / `submitWithdrawal(amount)` | 提现 |
| 场景投影：`loadPlatformScenario(preset)` / `loadExpertScenario(preset)` / `reset` | 演示控制器 |

权限边界（服务端强制，演示实现模拟）：运营方法仅 `platform_reviewer`；专家方法仅本人有效任务；命中回避禁止指派；非本人任务返回 `FORBIDDEN`。

## 7. 演示场景控制器

- **运营端控制器**（`PlatformDemoScenarioController`，仅 `VITE_DEMO_MODE=true`）：
  - 主线场景：待派单 / 待接受 / 评阅中 / 即将逾期 / 已逾期 / 已拒绝待改派 / 更正处理中 / 已完成；
  - 快照原子替换论文阶段、任务状态、队列、候选、账单与通知；
  - 辅助：专家库资格状态（通过/审核中/驳回）、余额额度；
  - 一键重置（二次确认）。

## 8. 演示数据边界（必须声明的文案）
