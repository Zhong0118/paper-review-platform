# 7A-2 修复真实 PDF 与匿名检测

依据审查 B1、切片 0+1 与已授权修复路线。原始版/匿名版是 PDF；附件现有类型规则保留。

- 单文件实际上传默认 50 MiB，可通过 MAX_UPLOAD_BYTES 配置正整数；已向用户询问，未收到不同选择前采用该建议值。路由按流累计读取并拒绝超限（413），不信任 Content-Length；服务层写入与完成阶段再次检查。超限不得覆盖此前上传字节/哈希。
- pypdf 严格解析真实 PDF：原始/匿名文件必须声明 PDF 且实际可解析、有页面、不加密；伪造/损坏/加密在完成上传阶段 422，不设完成标记或替换版本引用。包含 /Encrypt 的普通文本不能仅凭字节命中判为加密。
- 提交时重新验证原始/匿名两份文件，覆盖历史伪 PDF、文件丢失或内容与 hash 不一致的情况；保留旧文件，明确拒绝，不自动改写历史版本。complete 已完成文件重试仍幂等。
- 使用解析正文与文档元数据（Info/XMP），同时检查文件名及论文标题/摘要/关键词中的姓名、学号、导师。Unicode 规范化并消除身份串间空白；中文压缩正文/元数据命中都 FAIL 并走已有自动退回。
- 任一页无可靠文本、有图片/表单等未覆盖内容、抽取异常或无法解释的字符，未命中身份也只能 REVIEW_REQUIRED；学校仍可人工通过或退回。文本清晰且无身份线索才 PASS，PASS 也保留学校门禁。无 OCR，不宣称证明文档完全匿名。
- 解析与抽取在工作线程执行，不阻塞事件循环；页数上限 1000，单页解压内容上限 2 MiB、全文抽取字符上限 2,000,000。超过解析支持范围明确拒绝/要求人工复核，不静默截断后 PASS。文件输入大小并不能保证任意恶意 PDF 的 CPU/内存上限，生产解析进程隔离仍需后续部署加固。
- 新增运行依赖 pypdf；ReportLab 仅用于测试生成真实中文 PDF。无数据库迁移、OCR、后台任务框架或页面扩展。

## 验证

真实中文/压缩文本、Info/XMP 元数据命中；清晰文档 PASS；空页/图片页 REVIEW_REQUIRED；伪造/损坏/加密拒绝；超限实际字节拒绝且旧文件不变；历史伪 PDF 无法重新提交；回退版本/学校门禁保持正确。所有既有文件与并发测试使用真实格式 PDF，保留故障注入的非法字节场景。

技术参考：[pypdf 文本抽取](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)，其明确不识别图片文本，且大内容流可能消耗大量内存。
