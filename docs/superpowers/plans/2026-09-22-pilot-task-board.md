## 换 agent 的执行约定

- 当前交付仍是未提交工作树；下一动作由真实环境输入和授权决定，不能从已解除的T07-2/T10工具链/T11-A1阻断重做。
- Astra 负责涉及隔离/权限/并发/规则的数据设计与审查。普通页面、明确接口、脚本由 Sol 执行。
- 发现需求冲突、需要改变公开接口/权限/状态模型、同一问题两次修复未通过时，记录最小复现和失败原因，转 Astra 诊断；不得通过删断言或放宽权限“完成”。
- 每项交付：实际改动、测试命令/结果、未覆盖项、工作树状态、下一项。不要复制整个历史对话；读入口文档和本任务相关代码即可。
- 本表状态必须附结果位置；本地完成、Hosted CI、浏览器、部署放行分别标记，不能相互替代。
- 同一工作树可直接换模型；换机器前必须交付包含未跟踪文件的完整快照，并排除真实密钥/私有文件。当前 HEAD 不包含近期实现。仅在用户另行授权后提交。
